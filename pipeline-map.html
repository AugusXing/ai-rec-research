召回 / 粗排 / 精排 / 重排 / 跨阶段统一

今天的关键变化可以直接映射到推荐链路：召回开始让 Semantic ID 承载业务结构、让 evidence navigation 决定向哪片候选空间扩展；精排开始按样本价值动态选择 fast/slow compute；重排继续与 retrieval expansion 融合；跨阶段统一则越来越像一个共享的 Structure + State + Budget control plane，而不是一个统一大模型。

今日链路判断：SPAR 属于“生成式召回的结构化 namespace”；GAREN 属于“召回扩展 + reranking 联合搜索”；DS-Frame 是精排 / sequential rec 内部的 compute router；ViSAR 是 retrieval-to-reader 的 adaptive candidate budget；NVIDIA speculative decoding 与 ANN scaling law 则决定整个链路的 Serving/TCO 边界。今天最重要的新词不是更大的 model，而是 domain constraint、marginal compute utility、evidence group、adaptive-k。

CAMIE / OrthoRec · Behavior & Topology-aware Multimodal Retrieval

召回值得押注：① domain-aware SID；② should-fire / source marginal utility；③ prefix survival；④ group/source navigation；⑤ adaptive-k；⑥ ANN/GR/Late-Interaction/Multimodal 多 source budget router；⑦ index scale/TCO model。
Tab 02 · 粗排 / Pre-ranking

Candidate Preservation × Source Calibration × Cheap Interaction

当前核心矛盾：候选来源正在从几个 ANN channel 扩展为 variable interest、GR beam、multimodal I2I、graph expansion、Agent tool retrieval。粗排不能只做“小精排”，而要先解决不同 source 的分布、重叠和预算。

SPAR 启发：结构化 SID 可以把地理层级 / semantic code 作为 source metadata，粗排阶段可显式做 reachability / freshness / business constraint 检查。

GAREN 启发：candidate generation 本身已包含 reranker feedback；粗排与召回边界会更模糊，需要记录每个候选的 retrieval path / group / expansion step。

ViSAR 启发：candidate count 不必固定。粗排输出也可以给 downstream 一个 confidence / stop signal，而不只是分数。

评价建议：Top-K retention、source retained ratio、candidate overlap、long-tail / cold-start coverage、constraint violation、feature freshness、state build cost、p95/p99、downstream lift。

Tab 04 · 重排与混排 / Re-ranking

Listwise Utility → Relevance Guard → Search-space Planning

GAREN · Reranker as Retrieval Navigator

GAREN 说明 reranker 不一定等候选全部生成后才工作；轻量 navigator 可以把 reranking signal 前移到 graph/group expansion，决定下一轮候选空间。

ICEGR RCPO · Relevance-guarded Business Preference

先限制语义相关集合，再用 click/pay/GMV 做 preference；避免商业 reward 把 relevance 冲掉。

TAAL PMI · Beam Survivor Calibration

只在完整 beam survivor 上做 O(B) PMI calibration，把 generative recommendation 的 rerank 扩展到 sequence level。

OC-SFT · Order-consistent LLM Scoring

presentation order 会影响 retained set；把 permutation consistency 训练进 scorer，代表 listwise stability 方向。

重排值得押注：Listwise utility、source/group quota、relevance guard、order invariance、risk/calibration、decision flip rate、search-space navigation、long-term value。

2026.09.03 推荐链路新增判断：“预算”已经成为推荐链路的新一等特征。 召回决定多少兴趣/source/group/k；精排决定是否进入 slow path；生成式 Serving 决定 draft/beam；ANN 决定 search width；评测决定哪些文档需要重新 judge。下一代全链路优化的核心目标会越来越接近 business utility per unit of compute / latency / evaluation cost。
