03 · Ranking

精排：Sequence/Interaction Unified → Intent / Uncertainty / Allocation-aware

2026 的 Ranker 不只学 CTR/CVR，还开始显式处理行为噪声、结构化意图、上游预测不确定性、请求算力预算以及上线后的流量分配。

04 · Re-ranking / Conversational / Memory

重排：Pointwise Score → List Policy → Reasoning Budget → Experience Memory

重排与 LLM 推荐的最新变化是：不再默认每次请求都重新进行完整 reasoning，而是把可复用推理转成持久经验。

05 · Cross-stage Runtime / Evaluation / Experiment
