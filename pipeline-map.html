召回 / 粗排 / 精排 / 重排与混排 / 跨阶段统一

今天链路图新增的核心变化在重排与跨阶段 Serving：hLLM 直接利用 permutation 结构，把生成式 reranking 从逐 token autoregressive decode 改成一次 prefill + Hungarian assignment；Faster Flash Decoding、vLLM 与 SGLang 则表明 runtime 正把 sparse selector、speculative decoding、parallelism、MoE balance 与 cache consistency 统一纳入执行契约。R²Adapter 进一步说明，召回/RAG 也应按 query 复杂度决定是否进入昂贵 graph path。

今日链路判断：召回从“找候选”走向 namespace + item posterior + adaptive retrieval path；粗排最值得做 shared state 与 request-aware compute；精排继续从 user-item pair 走向 context/slate state；重排正在同时消除重复 document compute 与自回归 permutation decode；跨阶段最终统一 state、budget、decode contract、cache lifecycle 与 experiment feedback。

不是所有 query 都需要 Graph RAG。R²Adapter 用轻量 routing + rewriting 动态决定 vanilla / graph path，不确定但偏向 graph 的 query 会被重写以暴露 multi-hop 需求；三项 multi-hop QA 上 graph-based usage 最高减少 59%，同时保持 comparable answer accuracy。Paper

Tab 02 · 粗排 / Pre-ranking

固定轻模型 → Shared State + Request-aware Compute

过去 24 小时没有一篇足够重要且证据扎实的新粗排论文，因此不为“每个 Tab 都塞新 Paper”而降低筛选标准。当前两条主线更重要：

第一，state 复用。召回侧已经产生 multi-interest / SID / context / document states，粗排应成为这些 state 的低成本消费者，而不是从 raw feature 重算。

第二，动态计算。DS-Frame / AdaWidth 已说明 easy/hard request 不必走相同深度；UniCon 的 context compression、DoPR 的 prefix budget、R²Adapter 的 expensive-path routing 都可迁移到粗排：先估计 marginal utility，再决定候选、层数或交互预算。

值得押注：user/context state distillation、source-aware pre-rank、candidate-set aware shallow interaction、early-exit / width routing、粗排与精排共享 backbone cache，以及直接以 recall@K × latency × downstream value 训练 budget controller。

hLLM · Single-pass Structured Generative Reranking

Research Impact Score / 研究价值 9.6/10工业成熟度 ★★★★☆创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 否；截至今日未确认官方仓库是否有线上 A/B 否阅读优先级 最高

排序输出天然是 permutation。hLLM 从一次 prefill 的 hidden states 读出 N×K item-position score matrix，再通过 Hungarian algorithm 求最优 bipartite assignment，合法排列由算法保证而不是生成后修复。LoRA + teacher ranking distillation 报告 28ms 端到端推理、64× speedup，同时维持与 teacher 相当的 ranking quality。Paper

对混排的启发：DoPR 消掉“同一 item/document 被反复编码”的成本，hLLM 消掉“最终排列逐 token 解码”的成本。两者可以天然组合：offline reusable item/document state → online user/query/list interaction → structured assignment。下一步应把 diversity、业务规则、广告/自然结果配额、position constraint 和 uncertainty 直接写入 assignment / constrained decoder。
