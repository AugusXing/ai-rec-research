召回 / 粗排 / 精排 / 重排 / 跨阶段统一

按工业链路判断论文真正落在哪里。今天的关键变化是：召回开始同时管理视觉 multivector 与 Agent trajectory；精排目标从固定 horizon 分类扩展为 time-to-event；跨阶段统一则进一步包含 context manager、precision router 与 Agent durable state。

今日链路判断：PULSAR 与 ITER 属于召回，但前者优化 Visual RAG Data Plane，后者优化 Agent trajectory-aware query state；Timing-Aware Repurchase 是精排/业务决策目标层的重要更新；ContextPilot 横跨召回、reasoning 和 memory，最适合放在“跨阶段统一”；HyQuant/H-Scale 不是某个 ranking stage 的模型，却决定所有生成式阶段的 Serving 预算，因此作为跨阶段基础设施维护。

Tab 02 · 粗排 / Pre-ranking

Candidate Preservation × Cheap Interaction × State Distillation

当前核心矛盾：候选规模大，但线上预算不能复制精排模型。最有潜力的方向不是简单缩小 Transformer，而是让长历史/多模态/Agent teacher 在离线产生 compact user/query state，线上粗排只做 candidate-conditioned cheap interaction。

2026.09.01 启发：PULSAR 的 two-stage pooling 本质就是“先用廉价 representation 保候选，再用昂贵 interaction 精筛”；这个模式可直接迁移到推荐粗排。ContextPilot 又提示 User State 不必永久把全部历史塞进模型，可以主动 fold/offload 后只保留 task-relevant state。

评价建议：Top-K retention、candidate-set overlap、feature freshness、state build cost、p95/p99 latency 与 downstream ranker lift，而不只看独立 AUC。
Tab 03 · 精排 / Ranking

Feature Interaction × Sequence × Causal / Temporal Decision

Timing-Aware Repurchase · Survival Ranking

一个 AFT survival model 替代 3 个 horizon binary classifier，总树数约减少 3×。Log-Normal 最适合纯 ranking，Exponential AFT 更适合需要概率的 surface（ECE ~1e-4），把“rank score”和“decision probability”显式分工。Paper

Stageboost · Counterfactual Action Ranking

eBay View-Item signal selection 从 outcome prediction 改成 counterfactual incremental value，线上整体 GMB +0.08%，P&A +0.58%。Paper

MaskRec / Scaling GNN

MaskRec 强调 Unified token space 仍需要 topology constraint；工业 GNN 强调复杂 graph expansion 可以离线化为 online ranking state。

精排值得押注：Time-to-event + Causal Value + Calibration。用户行为如果天然带时间与 treatment，不应继续全部压成 pointwise binary label。
Tab 04 · 重排与混排 / Re-ranking

Context / Risk / Diversity → Stable & Calibrated Decision

OC-SFT · Order-consistent LLM Scoring

相同 nDCG 不保证相同 retained set；presentation order 能让最终决策翻转。OC-SFT 把 permutation consistency 直接训练进 scorer。Paper

Survival Rec 对重排的新启发

即便 ranking metric 只差 0.3% relative，不同 survival family 的 ECE 可以相差一个数量级。重排输出如果还要进入阈值、通知、库存/促销 policy，就必须报告 calibration，而不能只报 NDCG/AUC。

重排值得押注：Listwise utility、candidate-set graph、order invariance、risk constraint、calibration、threshold stability、decision flip rate、长期 value。

2026.09.01 推荐链路新增判断：“跨阶段统一”的下一步不是删除所有阶段，而是让阶段共享同一个状态与预算控制面。 召回可以是便宜 pooled vector，重排可以是 exact interaction；用户历史可以 offload 后按需回读；KV 可以大部分 4-bit、关键 token 保高精度。统一的是 policy 与 state，不一定是每一步都使用同等昂贵的 computation。
