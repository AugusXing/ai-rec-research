Routing & Serving Contract

跨阶段统一层新增四类系统约束：Cost-aware Model Routing、Batch/Seed Determinism、Component-aware Cache State、Precision × Hardware Compatibility。推荐 / 搜索链路未来的 controller 不仅决定召回源、K、ranker 或模型，还要判断当前执行路径是否满足可复现性和状态一致性。精读 →

链路总判断：9/26 的新工作把“跨阶段统一”进一步推进到 Conditional Activation：retrieved candidate、available feature、retrieved Skill、stored memory、available model 都只是 candidate resource；是否真正消耗在线预算，应由当前 request state 与边际业务价值决定。未来链路更像 Candidate Generation → Conditional Activation → Specialist Execution → Counterfactual Measurement。
