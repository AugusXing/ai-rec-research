06 · Adjacent Track · Search / RAG Runtime

Agentic Search：推荐链路之外，但对“动态候选与计算预算”高度可迁移

EAHR 把 Hybrid Retrieval Depth 变成 Query-specific State；DocMemo 用 Page Belief 管跨轮探索；Search-R1 Stopping 学“什么时候不再搜”。这些思想可以直接迁移到推荐：Adaptive Recall Depth、Dynamic Rerank K、Long-history Reading Budget、Recommendation Reasoning Stop。

链路层面的总判断：“召回 / 粗排 / 精排 / 重排”仍然是理解工业系统的好坐标，但越来越不像不可改变的物理边界。Generative Retrieval、Unified Model Graph、LLM Policy 与 Adaptive Compute 正在把阶段接口重新参数化。未来的核心能力会是：在准确率、覆盖率、延迟、QPS、GPU 成本与业务目标之间，按请求动态决定这条链路到底跑多深。
