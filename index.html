今日结论 / 最值得看

2026.08.29

今日主线：推荐 / 搜索正在从“把 proxy metric 做高”转向“证明这个 metric 会导致正确决策、真实因果增量和数值正确的 Serving”。 PailitaoGR 把 Crop/OCR 工具能力蒸馏进单次原图生成式检索；OC-SFT 证明 nDCG 几乎相同的 LLM scorer，换候选顺序后 retained set overlap 只有 0.66–0.84；Evidence-aware RAG 说明更贴近答案证据的 retrieval metric 也不能自动推出下游 validity；eBay Stageboost 用反事实估计做 signal recommendation，线上 GMB +0.08%；misi 则把 ANN 优化扩展到 build cost、memory 与 refresh；SGLang Top-K issue 再次强调高性能 kernel 必须先守住 semantic correctness。
优先级工作核心判断
★★★★★PailitaoGR生成式图搜不一定在线调用 Crop/OCR；training-time tool teacher 可以蒸馏成 inference-time latent perception。
★★★★★OC-SFT重排评测要从 ranking quality 进入 decision stability；单次稳定 scorer 比多 permutation averaging 更值得工业化。
★★★★★Stageboost页面信号推荐应该优化“展示后增量”而非“看到它的人本来就会买”；eBay 线上 GMB +0.08%。
★★★★★Evidence-aware RAG指标与生成需求更对齐，不代表它自动适合 retriever training、system selection 或 answer-quality prediction。
★★★★★misiANN 的 Pareto 面应包含 Recall × QPS × Build Time × Peak RAM × Refresh Cost，而不是只看查询吞吐。
