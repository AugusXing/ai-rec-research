聚焦 LLM、推荐系统、搜索 / 召回 / 排序 / 重排、生成式推荐、Agent、RAG、推理与训练优化。每日只保留真正值得投入时间的进展，并持续维护年度演进、Paper Map 与推荐链路。

今日核心判断：今天最强的共同信号不是“再把一个更大的 LLM 放进在线链路”，而是把智能变成可复用、可热更新、可约束的系统状态。AliExpress 的 SAM-D2Q 把 VLM + GRPO 放到离线索引构建侧，线上仍走成熟 inverted index；IGPO 不更新模型权重，只维护与实时 inventory 解耦的 Policy Guidelines；Embedding Surgery 允许对少量 document vectors 做局部纠偏；AtomRec 把用户 memory 拆成可演化原子；PTDG 则让多任务依赖从固定 funnel 变成 item-conditioned graph。
