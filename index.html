今日核心判断：统一模型的下一步，不只是继续扩大 shared backbone，而是让任务信号和计算预算都变成动态的一等变量。工业推荐论文 MORE 把 multi-task information flow 从末端 task tower 前移到每一层 backbone，并在陌陌线上取得 usage duration +3.0%、interaction +3.6%、deep chat +2.0%，同时通过 request-level shared computation 把 scoring latency 降低约 30%。Serving 侧 SLOWeave 则把固定 prefill chunk 改造成 deadline-aware controller；Agent 侧 Elastic Horizon、EdgeMem 与 ReActNet 分别把交互长度、长期记忆和通信拓扑从静态设计变成可控制结构。
