今日结论 / 最值得看

优先级Paper方向关键价值
S+PinGER召回 / Semantic ID / 工业 Serving生成式召回在大流量真实部署的关键是让 SID 同时承担监督与合法地址，而不是将历史 L 个 SID 码位都放入 Serving 上下文。
S+SLIDE跨阶段统一 / 生成式召回 / Listwise Distillation用离线强搜索器构造完整 List 监督，使便宜的在线单轨 greedy Generator 学习多路径搜索结果；这是生成式重排值得优先验证的训练范式。
S+Octen-WebGR召回 / 超大规模检索 / Semantic ID生成式检索可扩展到 2 亿量级网页，但其优势集中在“新 query → 已熟悉的目标网页”；冷门新网页仍需密集/词法检索补齐。
S+ACARe重排与混排 / Agentic Search / Context RankingAgent 子查询命中文档，不代表文档对原始任务有用；文档评分必须与原目标、当前策略和历史证据对齐。
SCRIM召回 / 长行为序列 / Memory Serving避免每个请求把相同商品文本重复送进 LLM，把稳定 item 语义预编码成跨请求可复用的连续记忆。
SDPE-Rec重排与混排 / Diffusion Rec / 集合生成对无序 Bundle/List，扩散式并行生成在结构上更自然，但必须解决“语义分叉被晚决策”和“并行揭示过快损失质量”。
