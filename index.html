今日结论 / 最值得看

2026.09.01

今日主线：AI 系统开始从“平均分配算力”转向“敏感度感知的预算分配”。 PULSAR 用两阶段 pooling 把视觉 Late Interaction 做到真实企业 RAG；复购推荐用 Survival/AFT 把多个 horizon classifier 统一为时间分布，并明确 ranking 与 calibration 的目标分叉；ContextPilot 让 Agent 主动管理 context，并对关键编辑 action 做细粒度 credit；ITER 让 retriever 消费完整 search trajectory；HyQuant 与 H-Scale 则分别把 precision budget 下沉到 token 与 NVFP4 scale。对生成式推荐 / 搜索，最值得押注的是 State × Budget × Routing × Calibration × Correctness，而不是只继续扩大 backbone。
优先级工作核心判断
★★★★★PULSAR视觉 RAG 的生产化关键不是再堆 OCR，而是把 Late Interaction 的 token geometry、pooling、ANN、refresh 与 reader budget 一起设计。
★★★★★Timing-Aware Repurchase天然含时间的推荐任务应优先建模 time-to-event；排名 score 与概率 calibration 可以选择不同 survival distribution。
★★★★★ContextPilotContext management 正在从 truncation heuristic 变成可学习 policy，关键是 action space、探索位置和 credit assignment。
★★★★★HyQuant低比特不应均匀施加；vertical-line token 与 local window 说明 precision 本身可以 request/token-aware。
★★★★☆ITERAgentic retriever 应把“已经搜过什么”当作状态，已有 useful doc 甚至会在后续变成 redundancy negative。
