今日结论 / 最值得看

2026.08.30

今日主线：高性能 Serving 正从“Kernel Fast Path”进入“State Contract + Runtime Policy”阶段。 vLLM 修复 probabilistic speculative decoding 中 draft 与 target 共享 Gumbel noise 导致的输出分布偏差；SGLang 为 Dspark / Dflash 的 TP sampling decision 建立 rank-0 consensus，并修复 HiCache 以可复用 rid 作为异步 offload lifecycle key 的请求污染风险；vLLM NIXL 把 P/D KV transfer 扩展到 MLA+DCP；MoE 侧则开始系统消除 routing metadata 重算，并用 workload-aware kernel / launch routing 取代静态 heuristic。对生成式推荐与 LLM ranker 来说，概率语义、请求身份、并行状态与 KV ownership 已和模型指标同等重要。
