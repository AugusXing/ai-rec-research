今日结论 / 最值得看

优先级Paper方向关键价值
S+HGE / HSAE-PLL-RCEF商业化搜索 / 多层级价值预估 / 精排把一组动态商品作为候选容器建模，再把容器的商业价值分解到实际成交的商品层，避免只看容器分数。
S+DecoGenerative Retrieval / Semantic ID / Serving不让重型 LLM 为 SID 的每个码位反复推理：主干思考一次，再由小 Decoder 沿合法码树生成物品地址。
S+TCBSA生成式召回 / Test-Time Adaptation / Beam Search后融合救不回已被生成器丢弃的商品；先把强协同模型的得分转换成 prefix 势能，引导 beam 路径生存。
SIDM / CMMGenerative Rec / Semantic ID / 蒸馏让一次并行输出 48 个语义码头的学生，同时学会商品级选择分布和码位边际概率，兼顾 Recall/NDCG。
S+MICE-P搜索 / Retrieval-Rerank 联合 / PLAID Serving不必在高精度 Cross-Encoder 与低成本 ColBERT 间二选一：把可缓存文档表征与有限 Query-Doc 融合组合，并实测首阶段检索。
S+System One / Decision vs RerankerLLM Ranking / Model Routing / Fine-tuning同样大小的模型，通用“是否相关”决策能力不等于排序相关性能力：专用 Relevance 训练在中小参数规模可明显胜出。
