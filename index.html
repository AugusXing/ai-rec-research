今日结论 / 最值得看

2026.08.28

今日主线：推荐 / 搜索算法正在从“训练更强模型”走向“训练系统如何控制自己的演进、检索、记忆与信息流”。 阿里 Astar 把历史 commit 与实验曲线训练成 Evolution Model，在 Lazada 广告闭环连续 20 次自动迭代并获得 GMV +4.86%、广告收入 +1.82%；194M 用户 / 28B 边工业 GNN 用 Multi-hash 与 Temporal CSR 把图模型真正压进生产；ProRetrieval 让 4B 模型生成 SQL×Text×Image 的可执行检索程序；CoVeMem 把 Agent Memory 从文本摘要升级为 Collaborative Vector State；MaskRec 则用 TopoMask 说明统一 Ranking Backbone 必须显式控制跨域信息流。
优先级工作核心判断
★★★★★Astar算法研发的“下一步改什么”可以从历史实验中学习；真正值得沉淀的数据资产是 commit × metric × training curve × business context。
★★★★★Scaling GNN工业 GNN 的决定性设计是 representation memory、时间正确性与 sampler complexity，而不是再换一种 message passing。
★★★★★ProRetrievalAgentic Search 的 action space 从 query generation 升级到 executable retrieval program；4B RL 在电商 Hit@1 0.809。
★★★★★CoVeMemAgent Memory 应拆成 State Store + Retriever + Reader，而不是把所有用户信息都重写成自然语言。
★★★★★MaskRecUnified Backbone ≠ Full Attention；Topology-constrained information routing 可能成为下一代 feature interaction。
