今日结论 / 最值得看

2026.08.25

今日主线：Semantic ID 正从“生成式推荐内部编码”升级成跨检索、排序、搜索与 Serving 的系统接口。 快手通过单层大语义码本 + 协同消歧 token 把 GenRec 解码 FLOPs 近乎减半，并在线取得消费指标与 QPS 双收益；DoorDash 则让同一层级 Semantic Product ID 同时服务发现页排序和搜索 Query Reformulation。与此同时 Clarify-Then-Search、CAIRO、EnSI-RAG 都指向同一趋势：真正决定模型质量的越来越是“什么结构化上下文进入模型”。

★★★★★DoorDash One Hierarchy, Two Systems同一 Semantic Product ID 同时进入 Discovery Ranking 与 Search Reformulation，两个系统均有线上收益。
