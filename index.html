今日结论 / 最值得看

2026.08.23

今日主线：系统优化正在从“局部模块指标”升级到 State / Cache / Routing / Index Contract。CacheRoute 证明 Prefix/KV 命中率如果换来 hot-key 负载倾斜，系统容量反而可能下降；StateMem 将长期 Memory 从“检索历史事实”推进到“维护当前有效状态”；Semantic Cache 审计则显示 raw semantic hit 必须经过答案可替代性和 encoder-specific threshold 校准。索引与监督侧，MRL-aware variable-bit quantization 和 LLM Annotation × Click 都指向同一原则：资源和监督信号应该按价值、频率与结构动态分配，而不是均匀处理。
优先级工作核心判断
★★★★★CacheRoutePrefix locality 与 fleet load 必须联合规划；60×H100 上 p99≤3.5s 容量 176±11 QPS，约 2.3× 强基线。
★★★★★StateMem长期 Memory 的核心是 supersession、dependency propagation 与 current state，而不是把历史继续 append 到向量库。
★★★★★Semantic Cache / CLEVER复杂 eviction 基本没有赢过 LFU；51–60% raw hit 在答案可替代性审计后可能只剩 1.1–2.2%。
★★★★☆Variable-bit QuantizationMatryoshka embedding 的维度价值不均匀；固定 memory budget 下 PQ recall 最多 +8%、SQ 最多 +18%。
★★★★☆LLM Annotation × Click for LTR高频 Query 更信真实 Click，中低频更受益于 LLM 语义标签；Teacher budget 应 frequency-aware。
