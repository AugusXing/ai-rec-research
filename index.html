10/31 核心结论：生成式 List 要用真实反馈而非只模仿历史曝光，同时系统地识别 Reward 数据和 LLM Judge 的偏差。 UGR 线上 GMV +2.10%，GR4AD-X 线上广告收入累计 +3.07%；GistRank、Beyond IPS 分别解决长文本算力和无 propensity 反事实评估。

优先级Paper研究方向工业判断
S+ · 必读 ①UGR跨业务生成式 List Ranking / RL仅用曝光顺序 NTP 相当于模仿旧策略，缺乏点击/交易的偏好监督。约一千个异构候选让普通全注意力代价高，广告历史展示还受竞价偏差影响，不能直接把历史得分复制到在线商业拍卖。
S+ · 必读 ②GR4AD-X生成式广告 / Semantic ID / Prefix Reward固定量化 SID 对接近两个码簇边界的广告容易错路由；简单加深/加宽网络提高参数而损害 QPS；普通 beam 优先高概率前缀，过早丢弃高价值广告。
S+ · 必读 ③GistRankLLM Listwise / 文档压缩 / KV Serving单 embedding 不够精细、全文 cross encoder 又成本高。只测最终排序推理而忽略文档压缩/KV 构建，容易错误估计系统成本。
S+ · 必读 ④Beyond IPSOPE / 曝光偏差 / 多策略评估经典 IPS 需要已记录每阶段动作选中概率；naive DM 忽略曝光偏差，独立 domain reweighting 在新旧策略支持集不重叠时产生极大方差。高置信离线收益未必能在线复现。
S · 精读 ⑤Position BiasLLM Judge / Reward / 排列偏差诊断几次排列结果不同不能说明统计显著，更无法区分模型本身随机性与位置系统偏置。需要可复现的零假设与大量配平置换。
S · 精读 ⑥Merge and Branch生成式推荐 / Tree SFT / 训练成本历史 item 的标题/描述/SID 占据多个 token；每个正例目标都重复 T 长历史，W 个目标的内存约 W(T+L)，且目标分支之间不能互相看到未来信息。
