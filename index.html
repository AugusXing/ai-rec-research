聚焦 LLM、推荐系统、搜索 / 召回 / 排序 / 重排、生成式推荐、Agent、RAG、推理与训练优化。每日只保留真正值得投入时间的进展，并持续维护年度演进、Paper Map 与推荐链路。

10/26 核心判断：可信的检索效果必须能归因到被消费的证据与具体决策（LARA）；稀疏召回可利用图搜索减少查询时延，但建图/内存仍昂贵（GRIP）；循环模型通过训练约束共享 KV，系统收益应在负载条件下验证（BeNice!）。

今日结论 / 最值得看

优先级工作研究方向核心价值
S+LARAAgentic Search / 检索归因把检索列表、Agent 消费与最终成功串成可审计 lineage；没有归因就不能稳定训练 List-level Reward。
S+GRIPSparse Retrieval / ANN稀疏感知图搜索可在固定 Recall@10 下优于 Seismic 查询时延；建图和 RAM 成本需另外计算。
S+BeNice!Looping / KV Serving随机深度训练和 KV-compatible 后训练让多轮 loop 复用缓存；效率数据主要来自模拟负载。
SFlexVDR多模态召回 / Budget Routing按 Query 联合分配 encoder 深度、Embedding 宽度与 Token 数，而不只是固定压缩。
SJev-DLC纠错偏好 / 轻量持续学习将显式 preferred/rejected 纠错转成有界状态，不在请求链路中更新大模型。
SIRAHRAG / 自动管道搜索先搜索检索架构，再调数值超参；强离线分数不一定带来更低优化成本。
