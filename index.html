今日结论 / 最值得看

2026.08.18

今日主线：Retrieval 正从“固定模型 + 固定 Top-K”转成 Elastic Model + Ranked Discovery + Agentic Interaction + Learned Stopping。Tevatron-Elastic 把 Depth / Token / Embedding Width 统一成单 checkpoint 的运行点；BM25 Scaling Study 与 RARG 则共同说明：Agentic Search 不是抛弃 Ranking，而是让 Ranking 从 Top-K Filter 升级为执行先验。真正值得押注的是统一的 Request Value / Difficulty Router。
优先级工作核心判断
★★★★★Tevatron-Elastic一个 checkpoint 覆盖 Depth / Token / Width 多 operating point，为按请求分配 Retrieval/Rerank 算力提供工程接口。
★★★★★BM25 Wins at Scale28 个嵌套规模实验显示：语料放大后 Global Candidate Ranking 重新成为关键，Agent 更适合接在 ranked discovery 之后。
★★★★★RARGRelevance 不只决定“谁进入 Top-K”，还指导 Agent 先搜哪里、从哪开始、哪些局部证据先曝光。
★★★★☆KDD 2026 Research AgendaRAG for RecSys 与 GenRec 两个教程都把问题推向全链路：Retrieval/Tokenization/Optimization/Deployment。
