今日结论 / 最值得看

2026.09.02

今日主线：召回正在从“固定表示 + 固定预算”走向“可变兴趣集合 + 意图一致训练 + 动态 Serving”。 Snap SetMIR 用 Hungarian matching、presence gating 与 query-level NMS 同时解决 interest collapse 和 static dispatch，ANN 调用数减少 33%，线上整体 CVR +3.11%；百度 ICEGR 把 Query Intent 贯穿 SID 构造、SFT 与 Preference Optimization，20% 流量两周 A/B 获得 CTR +3.52%、订单 +15.96%、GMV +7.53%；CAMIE 进一步说明多模态 I2I 的第一杠杆是 co-engagement supervision，而不是盲目换更大 MLLM。生成式推荐侧，TAAL 把 91.9%–96.6% 的失败定位到 SID 前两步，提示必须优化 prefix survival；系统侧 vLLM 则继续证明 prefill/decode 应按 workload 分路优化。

★★★★★CAMIE工业多模态 I2I 中，行为监督带来的增益远大于 backbone family 差异；一模统一并不意味着纯视觉也该强行统一。
