今日结论 / 最值得看

2026.09.04

今日主线：AI × 推荐系统正在从“固定 Pipeline + 人工调参”进入“受约束的自主控制”阶段。 Meta CORAL 把 LLM Agent 放到生产推荐系统控制面，真实 A/B 证明它可以逐轮调 retrieval budget 或 Serving treatment；Declarative Attention 让模型显式声明该看全局、聚焦哪个 context block 或只做局部 reasoning；PRO-Step 将 RAG reward 从最终答案推进到逐步逻辑 + 证据 grounding；Spotify Shunt 与 NVIDIA PAIR 则让 routing 分别进入 model-cost 层与 device-compute 层。
优先级工作核心判断
★★★★★CORAL推荐系统 Agent 的高价值落点不是替代 ranker，而是自动化高杠杆控制面；已有两个大规模生产 A/B。
★★★★★Declarative Attention模型可把“哪里值得算”直接输出给 runtime，长上下文 attended tokens 下降 31.1%–52.0%。
★★★★★PRO-StepRAG 的 credit 应落到每个 retrieval/reasoning step，而不是只奖励最终答案。
★★★★☆Spotify ShuntModel routing 可先从 deterministic task decomposition 做起，I/O-heavy coding work 平均省约 90% 主模型读文件 token。
★★★★☆NVIDIA PAIR多 Agent Serving 正进入 request-level compute routing：模型不只要选“用谁”，还要选“在哪算”。
