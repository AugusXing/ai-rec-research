聚焦 LLM、推荐系统、搜索 / 召回 / 排序 / 重排、生成式推荐、Agent、RAG、推理与训练优化。每日只保留真正值得投入时间的进展，并持续维护年度演进、Paper Map 与推荐链路。

11/04 核心结论：真正值得追踪的不是更多生成 token，而是“可信 Reward/证据归因 → 训练目标与路径去偏 → 近线多工具决策 → 可控成本的线上执行”。淘宝 E-GenRM 与 CADRE 都把复杂判据放在训练/离线 Teacher、真实在线依赖更小的执行模型；1688 HERO 暴露了 SID 蒸馏的热门偏差；快手 EvoRec 证明可用 nearline Agent 控制召回与混排策略。

今日结论 / 最值得看

优先级论文技术方向工业证据判断
S+ ①E-GenRMReward / Shopping Agent / Preference Alignment有：淘宝购物 Agent 14 天随机线上实验（属于 Agent 后训练，非评价列表重排 A/B）Reward 不应只是一个黑盒标量：购物评判需要显式标准、证据支持、用户隐含偏好和缺失证据获取，而且必须通过真实在线用户指标检验。
S+ ②HEROGenerative Rec / Semantic ID / OPD有：1688 首页“猜你喜欢”15 天 A/B，GMV +3.412%On-policy 蒸馏不是天然多样化：教师本身偏向热门 token、学生很少 rollout 长尾 SID，两种曝光偏差会互相强化。
S+ ③CADRESearch / Relevance Verifier / Distillation有：电商搜索广告 7 天 A/B；RPM +1.69%、CTR +0.76%、相关性满意度 +0.3pp复杂相关性不是“更多 Agent 投票”而是让独立的属性、意图与业务规则证据由可训练 Verifier 仲裁；真正上线用蒸馏学生，而非多 Agent 同步串行推理。
S+ ④EvoRecAgentic Recommendation / Cross-stage Planning有：2026-08-28—09-03 快手 A/B，广告收入 +4.6%、CTCVR +3.5%Agent 在生产推荐中最有价值的角色可能是“近线决策控制器+反馈归责器”，而非每个请求都在前台链路生成商品列表。
S ⑤SIDRecSemantic ID / Discriminative Fine Ranking无；工业离线 AUC/UAUC/WUAUC 不等于线上流量实验SID 不只属于生成式召回：给精排直接用的离散表示也需要同时对齐内容语义、协同偏好和下游任务损失。
S ⑥USDBServing / Sequence Storage / Foundation Rec Infrastructure无推荐收益随机 A/B；为生产存储迁移和对照压测下一代推荐的瓶颈不只是更长 Transformer：用户行为更新又碎又频繁，而训练/Serving 反复要读数万条长历史，存储布局需成为模型架构的一部分。
S ⑦MUSELLM Recommendation / Reasoning Distillation无训练 LLM 推荐的“推理质量”不应看理由写得流畅，而应看它能否让真实目标在完整候选库的排名上升；学生探索可以超过单教师知识边界。
S ⑧DMRerankerReranking / Instruction Following / Constraint Satisfaction无检索系统经常“话题相关但忘了用户的附加条件”，分解每条约束并独立判断，再用乘法联合控制，比把所有 instruction 一股脑塞入 reranker 更稳定。
S ⑨PACERecSemantic Representation / Long-tail / Flow Matching无只用 LLM item embedding 解决了冷启动语义，但没有学会用户的顺序性偏好；热门物品的前序行为分布可为长尾表示提供协同方向。
