今日结论 / 最值得看

优先级工作研究方向核心价值
S+RouteWeaverModel Routing / 多阶段决策 / RL真正的 Routing 不是先选固定工作流再挑模型，而是联合选择单轮、多轮、Agent 三类流程与各阶段执行者；部署必须按查询效用扣除探索和协同成本。
S+Raw-RAGRAG / Agent 记忆 / 检索重排复杂 Agent Memory 未必打得过保留原始历史、先召回后重排的强基线；知识压缩可能把回答需要的关系链一起压掉。
SLychee召回 / ANN 索引 / GPU Serving在召回率趋近 1 的高精度区域，优化重点从继续调 HNSW efSearch 变成‘对 IVF 已扫描列表证明哪些点不可能进 TopK’，显著减少高精度距离计算。
SFormBench检索评价 / Hard Negative / Embedding模型在通用向量任务很强并不意味着能区分同领域细粒度技术细节：结构相近负例会反转 BM25 与通用 Embedding 的相对排序。
SOpenDS-WorldAgentic Search / 多模态工具 / EvaluationDeep Search 不能只评单跳 NDCG：真实开放 Web 需经过访问控制、音视频/文件解析、多工具验证和证据整合；最终答案对不对与工具时间损耗同样重要。
