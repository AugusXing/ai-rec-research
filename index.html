10/30 核心结论：当前最值得押注的推荐/搜索瓶颈是互补候选、完整证据交付与事实极性校准。MAGE 发现相似性孤岛；LESSRec 按 SID 粒度路由历史；QESChunker / Tessera 分别修复索引和读取端的证据断裂；CoverageBench-Negate 暴露 dense 的否定判别弱点。

今日结论 / 最值得看

优先级Paper方向核心价值 / 证据
S+MAGE多模态推荐 / 互补召回只建“语义相似邻居”容易漏掉互补商品；把协同行为中跨语义岛的残差显式写入多模态图表示。
S+LESSRecSemantic ID / 生成式召回SID 解码某一级时，无关层级的历史 token 可能是噪声；用层级匹配的历史 + item 全局语义双路读取。
SPDG-FAgentic Search / 偏好约束“想要 A，但必须满足 B，且优先 C”不是平铺关键词；把依赖关系先结构化再检索可避免约束错配。
S+TaskBridge商品搜索 / Query Reformulation从“活动意图”到“商品词汇”的 lexical gap，可以通过目录锚定和多候选改写显著减少。
S+TesseraRAG / 证据交付检索命中并不等于答案所需证据真正抵达 Reader；把碎片补齐标题、表头、章节路径，再同预算装箱。
S+QESChunkerRAG / Chunking / 检索Chunk 不必按字数/标点拍脑袋；用问题–证据监督直接优化静态索引中的完整证据覆盖。
SCoverageBench-Negate检索评测 / 矛盾与否定Dense Retriever 可能理解语义主题却忽略“没 / 不 / 不能”；利用最小否定编辑构造可衡量的检索反事实压力测试。
