今日结论 / 最值得看

2026.08.26

今日主线：Scaling 正从扩大 Raw Data / Context / Model，转向提高 Information Density 与主动分配有限预算。 蚂蚁在支付宝十亿级行为数据上观察到用户量、历史长度和 encoder 参数都存在明显饱和，并提出 User Behavioral Densing Law；北大 × 腾讯证明 Generative Search 的 Wider Context 会产生 relevance dilution，应改为因果反馈驱动的闭环 Context Allocation；SST 进一步表明生成式推荐的历史 token grammar 与预测目标 token grammar 不应强行统一；阿里 CRRN 则在线证明 trigger-aware 精排可以用极小延迟换来 CTR +3.87%、IPV +5.75%。
优先级工作核心判断
★★★★★User Behavioral Densing Law十亿级用户表征出现 Raw Scaling Wall；真正的 scaling unit 应从行为数量转向最小充分 token capacity 与信息密度。
★★★★★Laws of Context Allocation同预算下多轮闭环 context allocation 显著提升 evidence portfolio recall；“更多文档一次塞入”不是最优 scaling。
★★★★★Semantic Subword TokenizationHistory 可以用更高密度 semantic subword，Target 仍保持稳定 SID；非对称 tokenization 同时改善效果与序列成本。
★★★★★CRRN即时 Trigger Interest × 长期个性化兴趣级联融合；天猫线上 CTR +3.87%、IPV +5.75%，仅约 2–3ms 额外延迟。
★★★★★Reasoning Trace ≠ Recommendation Utility更 grounded 的解释不必然提高 Recall；LLM Rec 应把效果、推理质量、解释 UX 分开评估，并优先检查 reward density。
