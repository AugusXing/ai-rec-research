今日核心判断：Controller 正从系统外围下沉到生成 Policy、Rerank Reasoning、Attention、Speculative Decoding 与训练监督。UniPolicy 用 objective-specific policy 替代简单 reward fusion，并以真实 7-day A/B 证明多目标生成式召回可以进入工业链路；MERIT-Rank 把单条 CoT 重排升级为 multi-trajectory evidence portfolio；On-Demand Attention 与 SwitchSD 根据模型内部状态动态选择计算路径；RetireOPD 让 teacher 在不再有边际价值时自动退出；SPARSEUP 则提醒检索系统仍需要可解释、倒排友好的 sparse route。共同趋势是：共享 Backbone 继续做大，但真正的系统差异正在转向“什么时候走哪条执行路径”。

年度综述

年度主线已推进到：Generative Retrieval 的 objective-specific multi-policy、RL 的 teacher lifecycle、Reasoning/Re-ranking 的 multi-trajectory、Retrieval Representation 的 sparse / dense portfolio，以及 Serving 的 adaptive attention / drafting。

Paper Map

新增重点研究节点：多目标 Policy、Multi-Trajectory Rerank、Adaptive Attention、Adaptive Drafting、Teacher Lifecycle、DeepSearch Full-pipeline Reward、Tool Credit Assignment，并明确各自承接关系与下一步问题。

推荐链路

召回新增 UniPolicy + SPARSEUP；重排新增 MERIT-Rank；跨阶段控制新增 RetireOPD / F²DR / MATCH / ODA / SwitchSD。链路的主矛盾正在从“每个 stage 用什么模型”转向“每个 state 该走什么执行路径”。
