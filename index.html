今日结论 / 最值得看

2026.08.27

今日主线：Representation 正从“静态输入特征”升级成推荐 / 搜索系统的控制面。 快手 TAGR 让 Semantic ID、用户意图与 Preference Optimization 都能适应直播广告的分钟级变化，线上收入 +16.1%；腾讯 Tlow 用 Flow 重整 embedding geometry 后再做独立量化，微信图片召回全局 UCTR +10.32%；WeMM-Embedding 将多模态统一表示部署到检索、排序和序列建模并通过 14 个线上 A/B；淘宝 NMRL 则证明 CTR 原始标签不适合直接端到端监督共享多模态 Encoder；阿里 RecGPT-Mobile-V2 把 reasoning、模型与端云路径一起做 request-aware budget allocation。
优先级工作核心判断
★★★★★TAGR动态场景下 GenRec 的瓶颈不是 Backbone，而是 Fresh SID、Request-time Intent 与稳定的 On-policy Alignment；线上 Revenue +16.1%。
★★★★★Tlow先把复杂语义 embedding 变成低相关标准空间再独立量化；兼顾并行 decode、冷启动与大规模 token 参数复用。
★★★★★WeMM-Embedding多模态 Embedding 正成为 Retrieval / Ranking / Sequence 的共享资产；2B 已达到 8B 强基线水平，14 个线上 A/B 持续正收益。
★★★★★Native Multimodal Representation“端到端”不等于更好：先从 CTR 日志挖出可归因于内容语义的干净监督，再微调共享 Encoder，淘宝线上 CTR +1.5%。
★★★★★RecGPT-Mobile-V2端侧个性化 Query Recall 应按请求分配 reasoning / model / device budget；质量提升同时 CoT P50 62→14 token。
