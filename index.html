今日结论 / 最值得看

2026.08.19

今日主线：推荐系统的优化对象正在从“单个模型预测得准不准”扩展到 上线后的流量分配、候选生命周期、索引新鲜度和交互不确定性。Google Discover SDF 证明 Freshness 可以前移成独立 Candidate Lifecycle Filter；Impression Share Prediction 则把 A/B 中的系统流量后果前移到离线预测。与此同时，UniDot、NeuRoute 与 Ask to Be Sure 分别推进统一 Ranker、Fresh Index 与信息增益驱动的对话推荐。
优先级工作核心判断
★★★★★Google Discover SDF把 Supersession 与 Intrinsic Decay 拆开建模，生产部署同时改善过期内容、用户体验与 CPU/TPU 成本。
★★★★★Impression Share PredictionOffline Evaluation 不再停在 AUC/NE，而是直接预测候选 Ranker 上线后如何重分配展示流量。
★★★★★UniDot用统一 Dot-product Primitive 融合 Feature Interaction 与多域 Sequence Modeling，工业级竞赛 AUC 位居第二。
★★★★★NeuRoute十亿级 ANN 把 Index Build 压到亚小时级，让 Time-to-Index / Freshness 成为召回系统第一等指标。
★★★★★Ask to Be Sure用推荐分布熵下降定义“这次追问是否真的有信息价值”，把 Conversational Rec 改写成 Active Preference Learning。
