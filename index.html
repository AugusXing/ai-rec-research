优先级论文技术方向核心判断
S+ ①MILES-RecGenerative Rec / 意图生成 / List-level RL以 Qwen3.5-4B 的 Rich 设置为例，SFT→GRPO：Hit@50 1.50%→3.40%、SDA 34.97→51.37；Sparse 的 SDA 15.77→25.80。注意 Hit@50 绝对值仍低，不能把语义评分当作真实成交提升；某些 Sparse 大模型配置 Rec（无已核验线上 A/B）
S+ ②BrowseFlow用户模拟 / Flow Matching / 生成式推荐评测TaobaoBrowse ES=0.07264±0.00027、Count W1=0.0697±0.0051，明显优于基线 ES≈0.108—0.112、Count W1≥0.259；但 AUC 0.6126 低于 RL4RS-DIEN 的 0.6592，说明“分布生成更真”并不保证单点点（无已核验线上 A/B）
S+ ③Metacognitive SearchAgentic Search / Process Reward / GRPO论文在七集加权平均 CEM=69.3，HiPRAG 67.2（+2.1 pct）；统一 7B 比较平均 1.64 次搜索/题，对 HiPRAG 复现 1.76 次（约−6.8%）；需区分作者复现配置与原论文公布性能。（无已核验线上 A/B）
S+ ④Context as InfrastructureRAG / 知识编译 / Context Servingclaim-evidence 导航叶子在足够时少 91% query tokens，不足时多 1.9%，平均节省 38%；门控让测量延迟从 140 秒降至 30 秒。但 token savings 伴随部分检索轮次代价，不能外推成所有 RAG 场景 4.7 倍提速。（无已核验线上 A/B）
S+ ⑤ProSearch搜索 / 多条件匹配 / 精排与重排最强第一阶段 Qwen3-Embedding-8B 平均 nDCG@10=0.290，top100 后 Qwen3-Reranker=0.474；扩大到全文检索语料约 5.8 倍时该模型 nDCG 由 0.290 降到 0.206。研究强调剩余错误的核心是联合约束绑定。（无已核验线上 A/B）
S ⑥Fidelity Synopses召回 / ANN / Serving 预算路由16 个设置都比满足相同约束的静态方案便宜，成本中位数 0.72×，landmark batch lookup 为 21–32µs/Query；并非所有情况成本可减半，且存在 cell 内 Query 差异导致的不可达下界。（无已核验线上 A/B）
S ⑦CEU推荐治理 / 反事实解释 / 排序后处理报告的结论是“接近 full retraining 的遗忘效果，同时保留 utility”，离线指标/数据集需按原文表格对照才能复用，不能转换为线上 CTR/订单效果。（无已核验线上 A/B）
S ⑧Multi-Tool CompletenessAgent / 多工具检索 / 集合召回ToolRet 对≥4 所需工具的 Query，Completeness@10 仅约 0.08–0.17；AppWorld 上 75–90 样本训练的 Set Retriever 完整率 0.33，MCP-Bench 0.58，0 LLM 查询；层级导航约 0.30/0.40，却需要中位数（无已核验线上 A/B）
S ⑨Li²SAORL / 异步训练 / Advantage Bootstrapping定性结论：早期 Actor 不再被冷 Critic 拖累，后期转单采样改善效率/质量折中；具体 benchmark 的准确率与 GPU-hrs 需要对原文表格逐任务复现。（无已核验线上 A/B）
