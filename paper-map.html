主线 M · 2026.08.23 新增

Runtime State / Cache / Index Contract

核心矛盾：局部 proxy（cache hit、semantic similarity、history recall、uniform compression）更高，不保证端到端业务系统更好。

1. Cache Hit → Capacity-aware Routing
CacheRoute

Affinity、replication、LPT placement 联合优化；高 hit + 高 skew 可能反而降低 SLO capacity。

2. History Recall → Current State
StateMem

Supersession / dependency propagation 成为长期 Memory 的 first-class semantics。

3. Semantic Hit → Answer Substitutability
CLEVER

Threshold 必须绑定 encoder version；raw hit 必须经过答案可替代性审计。

4. Uniform Precision → Geometry-aware Precision
Variable-bit Quantization

固定 memory budget 下按 embedding geometry 分配 bit。

成熟度
★★★☆☆ → ★★★★☆

多数工作已有较强系统实验，但 State/Cache/Index 尚未被统一到一个生产控制平面。

精读路线

CacheRoute → CLEVER → Variable-bit Quantization → StateMem；先理解 proxy failure，再理解如何把状态、路由和索引精度联合建模。

值得押注
Utility × Freshness × State Validity × Substitutability × P99 × Memory Cost
