主线 B

Retrieval：Static → Test-time → Elastic

Retriever 不再是固定函数，Query 表示与模型运行点都成为 Runtime State。

1. Static Dense Retrieval

训练完成后 Query → Embedding → ANN 基本固定。

2. Query-side Test-time Adaptation

TTT-Embed 冻结 Encoder / Index，用 Reranker Reward 优化 Query Embedding。

TTT-Embed
3. Reasoning-before-Embedding

GEM 先生成 Reasoning，再产生 Embedding Token。

GEM
4. Elastic Operating Point

Tevatron-Elastic 用一个 checkpoint 覆盖 Depth / Token / Embedding Width，多种 Retriever/Reranker 运行点在部署时选择。

Tevatron-Elastic下一步：Query Difficulty → Model Granularity。

推荐精读路线

  1. 生成式推荐：FORGE → OneRec-V2 → FSGR → DrIG → Sona。
  2. 召回 / 检索：TTT-Embed → GEM → Tevatron-Elastic → RARG → BM25 Wins at Scale，理解 Static Retrieval 如何变成 Runtime Policy。
  3. 精排 / 重排：RankMixer → OneRank → DrEM → GR2 / REAM。
  4. Serving / 系统：TM20K → CoinRAG → SilverTorch → Tevatron-Elastic，重点看 Cost / QPS / Latency 如何进入算法设计。
  5. 未来选题：优先关注 Per-request Compute Allocation、SID Fairness、Uncertainty-aware Ranking、Relevance-guided Agentic Search 与 Hybrid GenRetrieval。
