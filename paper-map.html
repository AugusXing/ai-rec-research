Retrieval：Static → Adaptive → Elastic → Fresh Index

Retriever 不再是固定函数，Query 表示、模型运行点、Index Age 与 Rebuild Cost 都成为 Runtime State。

TTT-Embed

Tevatron-Elastic

主线 D

Lifecycle：Recency Feature → Eligibility Filter

“这个候选还值得被排序吗？”开始从 Ranker 内部特征变成独立系统。

1. Age / Time-decay Feature

传统 Recency 主要作为精排输入，仍让大量明显过期候选消耗完整 Serving 成本。

2. Relational Supersession

SDF 用 LLM Teacher → Student 蒸馏判断内容是否被后续内容取代。

3. Intrinsic Decay

多模态模型预测内容多个未来时间窗的寿命并生成可缓存 Item-level 信号。

Google Discover SDF★★★★★
4. Next

Freshness / Quality / Safety / Inventory / Dedup 统一成 uncertainty-aware Eligibility Layer。
