今天的技术树增加了一条非常关键的横向主线：Information Density / Budget Allocation。Densing Law 说明长历史并不等于高信息量；SST 说明 history 与 target 不必共享同一种 token grammar；Context Allocation 说明更宽 context 不等于更多有效证据；Reasoning Gap 又说明更多可读推理不等于更强推荐。下一阶段真正值得押注的是：表示怎么压缩、预算怎么分配、奖励怎么对齐。

如何读这张图：每条主线都按“上一阶段解决了什么 → 留下什么核心矛盾 → 哪篇关键工作推进了一步 → 下一步值得押注什么”组织。表中固定展示 7 字段：Research Impact / 研究价值、工业成熟度、创新性、与你方向相关度、官方开源、线上 A/B、阅读优先级。
主线 A

User Scaling：Raw History → Behavioral Densing

上一阶段

长序列推荐与 User Foundation Model 主要依靠扩大历史窗口、用户覆盖和 encoder capacity，让模型从更多行为中学习长期兴趣。

核心矛盾

重复支付、重复消费、习惯性浏览让 raw token 增长快于新增信息；训练 loss 可以继续下降，但下游 user representation 已经饱和。

关键推进

User Behavioral Densing Law 在支付宝十亿级行为数据上定量描述“最小充分 token capacity”随数据规模增长的规律，并用 ALGN 给不同用户 / 行为动态分配 residual depth。

主线 B

Generative Retrieval：Dynamic SID → Asymmetric Token Grammar

上一阶段

OneRec / Sona 将 item 变成 token；SIDScope 管理 tokenizer/mapping/generator；Dynamic Single-Level SID 用大单层码本减少 decode depth，并解决静态多层码本的 conditional sparsity。

核心矛盾

即使 SID 本身更好，历史侧仍可能被固定长度原子 token 拉长；而让 target 也变成可变 subword 又会破坏 rare-token frequency 与 constrained decoding stability。

关键推进

SST 只压缩 history grammar、保持 target grammar 固定；ANR-DiffRec 则让 collaborative co-occurrence 同时进入 SID 与 diffusion noise schedule。Tokenizer 研究从“量化几何”扩展成“语义、协同、训练动力学、Serving Grammar”的联合问题。

主线 C

Foundation / Cross-system：Shared State + Shared Semantic Asset

上一阶段

OneModel 将 Rec / Ads / Merchant 统一成 Event Sequence + Shared User State；DoorDash SPID 让同一 Product Hierarchy 同时支持 Discovery Ranking 与 Search Reformulation；RecPFN 用 support retrieval 做无梯度新域适配。

核心矛盾

共享模型不代表所有任务需要同样的上下文、token granularity 或实时 state。跨业务越多，表示的压缩、版本与 adapter 反而越重要。

主线 D

Context Selection：Clarify → Measure → Allocate

问题变化

RAG / Deep Search 从扩大 Top-K 和 context window，逐渐暴露三类失败：query 本身不完整、候选 context 噪声过多、模型反复消费已经覆盖的信息。

承接关系

Clarify-Then-Search 先补齐用户问题；CAIRO 按 user-item 选择 item profile；EnSI-RAG 用 entity structure 定位 evidence；今天的 Laws of Context Allocation 再用 causal LOO 测量“模型到底用了哪条证据”，闭环调度下一轮 context。

主线 E

Ranking / Re-ranking：Long-term Interest → Request Anchor → Utility / Risk

上一阶段

RankMixer / OneRank 把精排 Transformer-native；OneModel 共享 User State；CAIRO / StateMem 让重排开始消费 profile 与 current state。

关键推进

CRRN 在 trigger-induced recommendation 显式融合“刚刚点了什么”与长期兴趣，线上 CTR +3.87%、IPV +5.75%；Reasoning Gap 说明更漂亮的自然语言 trace 不能代替 recommendation utility；Risk-Aware Tool Reranking 则把 relevance × operational risk 变成 Agent action space 的前置重排目标。
