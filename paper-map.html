Research Problem Map · 更新至 2026.09.02

不是按年份堆论文，而是沿“核心矛盾”读技术

今天新增五条尤其值得追踪的问题链：多兴趣召回怎样从固定 K 个向量变成可变集合？Generative Retrieval 怎样保持 SID/SFT/Preference 的意图一致？生成式推荐为什么要显式优化 early-prefix survival？多模态 item embedding 应优先换 backbone 还是换监督？Retriever 怎样消费 downstream reward 又不破坏冻结索引的 geometry？

今日推荐精读路线：如果只读 5 篇，按 SetMIR → ICEGR → CAMIE → TAAL → PAO。第一篇看多兴趣召回如何从 representation 升级为 assignment/dispatch；第二篇看工业级生成式检索的全链路意图一致性；第三篇看行为监督如何重塑多模态商品空间；第四篇看 Semantic ID 的 early-prefix failure；第五篇看 frozen-index 场景下的 retriever RL。做生产 RAG 再补 PULSAR，做 Agent 再补 ContextPilot/ITER，做 Serving 再补 vLLM QSA Split / HyQuant。
问题 01 · 多兴趣召回为什么不能永远固定 K 个 Query？

Single Vector → Fixed Multi-interest → Variable Set Prediction + Dynamic Dispatch

核心矛盾：不同用户真实兴趣数量不同；固定 K 个 head 容易多个 query 追同一 target，也无条件消耗 K 次 ANN 调用。

承接关系：MIND / ComiRec / KuaiFormer → SetMIR：Hungarian one-to-one matching + presence head + query NMS + dynamic ANN depth。

Research Impact Score / 研究价值 9.4/10工业成熟度 ★★★★★创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 未发现是否有线上 A/B 是阅读优先级 最高

代表 Paper：SetMIR。10 个固定 ANN query 经 presence + NMS 后平均 6.70 个，R@10 保留 99.2%；线上整体 CVR +3.11%，与同 embedding/index/quota 的 I2I source 对比 CTR +44%、CVR +51%。

值得押注：learned should-fire probability、interest marginal utility、cross-source budget、latency/TCO-aware dispatch、candidate overlap-aware assignment。

问题 02 · Generative Retrieval 的各阶段为什么会“各自正确、整体跑偏”？

Content SID → Log SFT → Business Preference → Intent-coherent End-to-end GR

核心矛盾：内容 embedding 构造的 SID 不一定对应用户搜索意图；真实日志监督覆盖不足；直接用 GMV/交易做 preference 又可能牺牲 relevance。

承接关系：TIGER / OneRec → Query-aware Semantic ID → Synthetic Query Expansion → Relevance-calibrated Preference → ICEGR。

Research Impact Score / 研究价值 9.1/10工业成熟度 ★★★★★创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 未发现是否有线上 A/B 是，20% 流量两周阅读优先级 最高

代表 Paper：ICEGR。Recall@20 +21.7%、NDCG@20 +26.6%；线上 CTR +3.52%、订单 +15.96%、GMV +7.53%。SQE-SFT 占累计 Recall 增益约 76.7%，说明 catalog-wide supervision coverage 是大头。

值得押注：fresh/query-conditioned SID、cross-stage objective audit、synthetic-to-real curriculum、beam cost、GR/ANN source joint routing。

问题 03 · Semantic ID 生成失败，到底错在 Decoder 的哪一步？

Final NDCG → Prefix Survival → Early-branch Coverage

核心矛盾：层级 SID 的第一、第二步一旦被 beam 剪掉，后续解码再准确也无法恢复。

承接关系：RQ-VAE / LETTER-TIGER → Beam-search diagnostics → TAAL：history-conditioned joint-prefix target + forward KL + survivor PMI calibration。

Research Impact Score / 研究价值 8.3/10工业成熟度 ★★★☆☆创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 未发现是否有线上 A/B 否阅读优先级 很高

代表 Paper：TAAL。91.9%–96.6% retrieval failure 位于 SID 前两步；NDCG@10 在 Beauty/Instruments/Yelp 分别相对 baseline +39.5%/+6.7%/+28.6%，full-SID survival 提升 3.9%–16.6%。

值得押注：dynamic beam allocation、uncertainty-aware prefix branching、neural transition prior、SID construction × decoding joint training、prefix survival dashboard。

问题 04 · 多模态 Item Embedding 的第一杠杆是 Backbone 还是 Supervision？

Content Similarity → MLLM Embedding → Co-engagement-aligned Geometry

核心矛盾：预训练视觉/语言空间反映内容相似，不必然反映用户连续点击、加购、购买的行为相似。

承接关系：CLIP/SigLIP/MLLM Embedding → behavior pair mining → CAMIE。

Research Impact Score / 研究价值 8.5/10工业成熟度 ★★★★★创新性 ★★★★☆与你方向的相关度 ★★★★★是否官方开源 未发现是否有线上 A/B 是阅读优先级 最高

代表 Paper：CAMIE。Qwen3-VL 同 backbone 经 co-engagement fine-tune，R@10 相对 pretrained +37.7%；而统一监督下 Qwen/SigLIP2/CLIP 差距仅约 5.5pp。线上整体 DPA CVR +1.911%，对 text I2I control CTR +18.958%、CVR +13.12%。

值得押注：pair mining、multi-event weighting、fresh item encoding、behavior/content multi-objective、pure-image specialist router。

问题 05 · Frozen Item Index 下，Retriever RL 为什么不能像普通 Policy Gradient 一样 Push Away Negative？

Contrastive Retriever → Reranker Distillation → Geometry-preserving RL

核心矛盾：真实业务中 item/document index 重建昂贵，常见做法是只快速更新 query tower；标准 RL 对 negative advantage item 反向排斥，可能破坏已冻结的语义 manifold。

承接关系：Contrastive Dual Encoder → downstream reward / reranker feedback → PAO：只对 positive advantage retrieved item 更新。

Research Impact Score / 研究价值 8.2/10工业成熟度 ★★★★☆创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 未发现是否有线上 A/B 未披露阅读优先级 很高

代表 Paper：PAO。核心价值不是新 reward，而是把“frozen document topology”作为 RL 更新约束。

值得押注：query-only continual alignment、rebuild-cost-aware RL、off-policy logged reward、positive-only update 的理论边界、reranker→retriever credit transfer。

问题 06 · 多模态 RAG 怎样同时保留视觉细节与低延迟？

OCR-first → Unpooled Late Interaction → Pooled Two-stage Late Interaction

Research Impact Score / 研究价值 9.8/10工业成熟度 ★★★★★创新性 ★★★★☆与你方向的相关度 ★★★★★是否官方开源 完整系统未确认是否有线上 A/B 无；有生产部署阅读优先级 最高

代表 Paper：PULSAR。compact pooled prefetch + finer pooled MaxSim rescoring；ViDoRe V3 retrieval metric 损失 <0.01，median vector-search 约 15.1× 更快、RAM 约 14× 更低，生产覆盖 2.4M 页。

值得押注：query-aware pooling、region-level second stage、visual/text dual-index router、refresh-aware multimodal index。

问题 07 · Agent Search 的 Retriever 与 Context Manager 为什么必须共享 State？

Step-local Retrieval → Trajectory-aware Retrieval → Proactive Context Control

核心矛盾：下一步要搜什么取决于已经搜到什么；但完整 trajectory 越来越长，反过来又挤压 context budget。

承接关系：Search-R1 → ITER（main question + previous subqueries + redundancy negatives）→ ContextPilot（fold/offload/memory + fine-grained RL）。

Research Impact Score / 研究价值 9.5/10工业成熟度 ★★★★☆创新性 ★★★★★与你方向的相关度 ★★★★★是否官方开源 ContextPilot 是是否有线上 A/B 否阅读优先级 最高

值得押注：coverage-aware negative、context/retrieval joint RL、tool should-fire probability、cross-session memory freshness。

问题 08 · Offline Ranking Metric 能否支持真实业务决策？

nDCG/AUC → Decision Stability → Calibration → Causal / Temporal Value

承接关系：OC-SFT 说明相同 nDCG 可以产生不同 retained set；Stageboost 用 counterfactual incremental value 证明 action ranking 需要因果增量；Timing-Aware Repurchase 说明 ranking 相近时 calibration 仍可相差一个数量级；ICEGR RCPO 再说明 business preference 必须有 relevance guard。

值得押注：Decision Stability、Calibration、Causal Incrementality、Time-to-event、offline→online validity contract。

问题 09 · Serving 的“一个 Kernel / 一种精度 / 一个 Capacity”为什么不够？

Uniform Runtime → Sensitivity-aware Precision → Phase-aware Execution

承接关系：HyQuant/H-Scale 把 precision 下沉到 token/scale；vLLM QSA Split 再把 sparse attention indexer 按 prefill/decode 分路，GB300 prefill 4.15×–9.37×；SGLang 把 ragged graph request/token capacity 解耦；TensorRT-LLM 把 E4M3→BF16 widening 融进 decode kernel register。

值得押注：prefill/decode/spec-decode 独立 benchmark、request/token capacity contract、phase-aware kernels、semantic correctness guard。

问题 10 · 生成式推荐训练为什么会高估自己的在线鲁棒性？

Teacher Forcing → Wrong-prefix Exposure → Robust Multi-target Training

代表节点：MERIT 在 25 万+ interest category 的生成任务中把 gold 与 hard-negative label 打乱形成错误前缀训练环境，内部 global recall 至少 +11.9%、平均 Hit@k +6.1%，生产 user conversion +0.26%。它与 TAAL 一起说明：Generative Rec 的核心训练-推理 gap 是“错误前缀改变后续状态”，而不只是 exposure bias 这个抽象标签。

值得押注：prefix perturbation、scheduled/on-policy decoding、error-state recovery、beam survival × exposure-bias joint training。

2026.09.02 Paper Map 新判断：现在最值得押注的不是某个单一大模型，而是三类“结构变量”：Assignment（哪个兴趣/source 应该激活）、Alignment（表示/SID/监督/偏好是否同目标）、Survival（正确候选能否穿过多阶段剪枝）。它们分别对应 SetMIR、ICEGR、TAAL，也是召回与生成式推荐从 demo 走向工业系统时最容易被 backbone 指标掩盖的真实瓶颈。
