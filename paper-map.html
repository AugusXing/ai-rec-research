不是按日期堆论文，
而是沿着“核心矛盾怎么变化”去读

当前技术树最值得关注的五个变化：Semantic ID 从输出变监督接口；Foundation Ranking 从单场景扩大到 Shared User State；RecPFN 把“跨域适应”从 fine-tune 改成 support-conditioned in-context inference；向量/Token 压缩从 reconstruction 走向 downstream-ranking aligned；Runtime 从 latency/QPS 扩展到 cache、precision、determinism、input contract 和 hardware routing。

如何读这张图：每条主线先看“上一阶段解决了什么”，再看“留下的核心矛盾”，最后沿代表 Paper 到值得押注的问题。表中的 7 个评分字段固定为：Research Impact / 研究价值、工业成熟度、创新性、与你方向相关度、官方开源、线上 A/B、阅读优先级。
主线 A

Generative Retrieval → SID as Control Interface

上一阶段

OneRec-V2 / Sona 解决“Item 能否 Token 化并生成”，FSGR / DrIG 处理 SID frequency / coverage。

核心矛盾

纯生成存在 Beam Cost、Prefix Error、Fresh Item / Churn；纯 Dense ANN 又缺少结构监督。

关键推进

SIDScope 将 Tokenizer→Mapping→Generator 变成 artifact contract；SSR-GRPO 用 SID prefix 反向监督 Dense Retrieval，最终 Serving 仍走 ANN。

主线 B

Foundation Ranking → In-context Adaptation

上一阶段

RankMixer / OneRank 将精排 Transformer-native；OneModel 把 Rec / Ads / Merchant 行为统一成 Event Sequence + Shared User State。

核心矛盾

跨域预训练仍可能学到平均化规律，新业务/新国家/长尾类目继续需要微调。

2026-08-24 分叉

RecPFN 在合成 SCM 环境上预训练“序列推断算法”，部署到新域时只取少量 support sequence，无梯度更新；context retrieval 本身成为适应器。

主线 D

Index Compression：Uniform Reconstruction → Task-aligned Geometry

上一阶段

PQ/SQ 通常把所有维度/Token 看成同等重要，目标是最小化 reconstruction error。

两条新路线

Variable-bit Quantization 根据 Matryoshka embedding 维度结构分配 bit；CrossQ 根据 late-interaction ranking 敏感度保护 winner token、candidate score distribution 与 hard-negative margin。
