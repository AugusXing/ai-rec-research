过去一年：推荐系统正在经历一次架构级迁移

从 Cascade 到 Generative Recommendation，从特征工程到 User Foundation Model，再到 RL / Reasoning / Full-stack Generation。

年度核心判断：过去一年最重要的变化不是“LLM 被接入推荐系统”，而是 Generative Retrieval → Scaling/RL → Foundation Model → Reasoning → Full-stack Replacement 连成了一条清晰的工业路线。

1 · OneRec 系列：Scaling → Foundation Model → Reasoning

理解过去一年生成式推荐，最适合沿 OneRec-V2 → OpenOneRec → OneReason 这条线读。

OneRec-V2 解决大规模 Generative Rec 的计算瓶颈，通过 Lazy Decoder-Only 等设计显著压缩训练和推理成本，并把 RL 更明确地引入真实用户反馈对齐。

OpenOneRec 把目标从“更大的推荐模型”推进到“同时理解用户、Item、语言和世界知识的 Recommendation Foundation Model”。

OneReason 则开始探索 “Think before Recommend”，并明确指出：仅仅给推荐模型加一个 Thinking Mode 并不会自然带来收益，Item Semantic Alignment 与 Preference Reasoning 是前置条件。

未来：Per-request reasoning budget、长期 reward、Semantic ID 与自然语言语义空间对齐。

2 · JD GenRec：工业 Generative Retrieval 的三个现实问题

长序列、one-to-many 监督歧义、Reward Hacking，是生成式召回进入生产后必须正面处理的问题。

核心技术包括 Page-wise Next-token Prediction、Asymmetric Token Merger，以及结合 NLL Regularization / Hybrid Reward / Relevance Gate 的 GRPO-SR。作者报告首页线上实验中 Click Count 和 Transaction Count 均获得明显提升。

3 · Netflix：Scaling、GenPage 与 LLM Ranker 三线并进

Netflix 的信号是：未来推荐系统既可能“生成 Item”，也可能“生成整个页面”，还可能把传统 Feature Engineering 改造成 Context Engineering。

Scaling 工作指出推荐任务并不一定都遵循简单的“模型越大越好”；GenPage 直接生成多行 Homepage；GenRec 则以 verbalized user history + foundation LLM 构建 Ranker，并专门优化 Serving。

4 · GR2 / MetaStrategy：Reasoning 与 Policy 化重排

生成式重排正在分成两条路线：直接用 Reasoning Model 做列表决策，或让 LLM 只生成 Ranking Policy，再交给传统系统执行。

GR2 把 Semantic ID、Reasoning Trace Distillation、RLVR 与 Serving Distillation 串起来；MetaStrategy 通过结构化策略 JSON 兼容成熟业务规则和现有 Ranker，更接近渐进式工业落地。

5 · Sona：Full-stack Generative Recommendation

Sona 是过去一年最强的架构级信号之一：一个共享 User Encoder 的生成式模型开始直接替换 15+ 召回源、Pre-rank 和 Rank。

它把 Semantic ID、长序列用户建模、生成候选与 Teacher Ranking Distillation 统一起来。作者报告线上 Active Users、Listening Time 与 Likes 均显著提升。

关键未解：Catalog Coverage、Exploration、长期实验、跨场景泛化与在线推理成本。

原始来源：arXiv: Sona Technical Report

6 · Agentic Search：从 Retrieval 走向 Context Ranking

搜索 Agent 的核心问题正在从“搜到什么”扩展到“哪些 Evidence 值得占用 Context Budget”。

Agentic-R 强调用最终回答正确性训练 Retriever；CoSearch 把 Retriever 与 Reasoning Agent 联合 RL；RISE 把检索结果变成可交互 Workspace；Context Interference 则进一步证明，检索到的噪声会直接干扰后续推理。

未来：Evidence Ranking、Context Refiner、Context Budget Allocation、Tool / Model Routing。
