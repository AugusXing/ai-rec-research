业务动机 / 现有瓶颈

Shopify 商品目录达数十亿，商家、商品信息高频变动，传统搜索/推荐多模型链路负担重；统一生成 SID 必须兼顾购买相关性与极低尾延迟。核心冲突：更大码本、复杂解码提高相关性却损失 p95/p99，且生成地址与真实可售商品有映射碰撞。

模型架构 / 技术方案与模块

先基于目录内容表征构建三级 RQ-KMeans SID（采用 8192³ 配置，权衡码本与推理延迟），预训练混合商品属性、搜索 query-商品和用户行为序列；搜索引入多 token prediction (MTP) 快速生成 SID，额外 350M LFM2 排序器联合读 250 个候选；推荐侧使用 AR 与 joint-probability decoder，将碰撞 SID 解回候选商品。两条路径共用语义地址，不强制同一 Serving 解码策略。

训练 / Loss 与监督来源

联合预训练以 SID 生成的 token likelihood 为主要监督，覆盖目录字段、搜索与推荐样本；后续搜索用 RL 提升 judge relevance，从任务专家蒸馏提升推荐而未检出搜索损失。搜索后置 ranker 从 Qwen3.5-9B judge 的软标签蒸馏，以 BCE + LambdaLoss + query-embedding cosine 三项联合训练。注意 RL 后的受益不是简单映射到评论 List-level Reward。

推理 / Serving / 端到端成本

搜索 MTP 在单次 prefill 预测多 token，后接 350M ranker；推荐仍用 AR/joint-probability product resolution。搜索模型选择 LFM2-2.6B 而非更大 Qwen3，因为 p95 更好。三级码本从 8192³ 扩到 32768×8192²，在 100 RPS 下 p95 由 40.5ms 增至 50.0ms，150 RPS 时大码本甚至饱和到 2,221ms；必须量化极限负载而非平均速度。

实验协议 / 离线指标 / 线上 A/B

离线搜索以 OneDCG@10、购买 Recall 等评估；在推荐实际候选池中，每个生成器 top200，70,747 个有后续购买的用户，SID-LLM Recall@50=24.61%、独有的 incremental pool recall=2.65 个百分点；recent engagement 仅 1.64。首页推荐 A/B 的受影响版位订单 +7.95%、转化用户 +8.60%、CVR +9.85%，均报告 Dunnett 调整后显著。不同评价协议的绝对分数不能横比。

与主流方法对比 / 技术优势与局限

优点是共享 SID 表达，同时为搜索/推荐选不同解码器，把增量候选覆盖率作为真实价值；相对独立 HSTU/最近行为召回有独有购买覆盖。局限是供应约束、同 SID 多商品、重训/日更表维护、商家季节性和实时可售库存；只报告增量候选及受影响版位，不表示评论 List 排序自动获益。

未解问题 / 研究方向 / 评价推荐落地建议

研究推进：对 SID 质量做库存时效、码本漂移与碰撞公平性监控；在同商品的多条评价下学习“评论观点 SID”，测相同候选数下 List 满意度/成交的增量贡献，再引入交互式 List Reward，而不是直接复制商品效果。工程技能：训练数据配比、MTP/AR 多形态部署、candidate pool marginal recall 与真实 A/B 口径。

业务动机 / 现有瓶颈

TIGER/OneRec 的基础生成式 SID 帮助端到端召回，但不同 SID 层之间存在强条件依赖；传统 NTP 把“已曝光未点击”忽略，按下一 token 的准确率不等于会话级正例顺序，更不等于 List 的真实商业价值。

模型架构 / 技术方案与模块

对多模态商品编码用 residual quantization 构造三级 SID；轻量 SID Encoder 显式编码层间依赖；主干使用 Sparse MoE、Dual Gated Attention 和 multi-target prediction，用户已观察历史允许双向交互；在一个生成 SID 对应多个商品时加 posterior-based intra-SID ranking，避免碰撞后随意吐出商品。

训练 / Loss 与监督来源

基础正样本 loss 是三个 SID token 的负对数似然；曝光负例对最近窗口中“曝光未点击”商品最频繁的一级 SID 前缀施加 -log(1-p(negative_prefix))；再以 group size=32 的 GRPO 与 LambdaRank 辅助 loss（系数0.5）兼顾策略价值和相对排序。作者的露出未点击负例并非无偏负反馈，存在 position/曝光/商品流量选择偏差。

推理 / Serving / 端到端成本

受约束 beam search 确保 SID 可映射合法商品；公开数据集 beam=10，线上 beam=50，部署在召回阶段而非评价终排；用 FlashAttention2，注意生成 SID 与多个商品的 posterior score 二次决策。训练披露使用 56 块 H800 GPU，未披露足够的实际在线 p99、每千次请求 GPU-ms 成本以做跨系统对比。

实验协议 / 离线指标 / 线上 A/B

四个公开数据集 Beauty/Toys/Food/MovieLens-1M 与 SASRec/BERT4Rec/HSTU/TIGER 等比 Recall/NDCG；MovieLens-1M NDCG@10 从 TIGER 的 0.0912 提升到 0.1059，Recall@10 0.1713→0.1955。工业 150M 用户、16k 离线评估，逐模块 HitRate@50 从 NTP 0.1416 到 RL 后 0.1997。线上广告 +2.24% ADVV、+0.59% CTR、成本 +0.56%；电商推荐 +1.08% GMV、+0.95% DAB；均为作者披露 p<0.05。

与主流方法对比 / 技术优势与局限

比纯 NTP/TIGER 多了负反馈监督和 List 相关的辅助排名；相比直接 RL 纯成交优化，LambdaRank 可缓解位置排序失配；但线上 gain 来自整套组合，不能归因 GRPO 一个模块。论文 Work in progress，未披露用户满意度指标、曝光去偏实验和足够完整的生产成本曲线。

未解问题 / 研究方向 / 评价推荐落地建议

评价生成式重排最值得迁移的是 positive item ranking + GRPO/LambdaRank 混合训练；严格使用真实展示位置/曝光概率进行点击负样本校正，并测真实评价满意度、负面观点覆盖、去重、成交权衡，避免“没点击=差评”。实验路线：NTP→Exposure Loss→List Reward→GRPO+LambdaRank 四组对照并做线上因果检验。

模型架构 / 技术方案与模块

Tier-1 小 LLM 每次重排并产出 LOW/MEDIUM/HIGH 置信度；路由器根据容易测量的用户历史长度、用户分层、Tier-1 结果来判断是否进入 Tier-2（多次 self-consistency / multi-path / 大模型）。论文讨论 R0-R3 四种路由器，但主要离线验证 R0 历史阈值，线上使用可审计的零延迟规则，并强调离线“冷用户升级”策略没有照搬上线。

训练 / Loss 与监督来源

本研究生产采用零样本预训练 LLM 重排，核心贡献在策略路由/Serving 与对照实验，<b>不是新 SFT、RL 或 List Reward 训练 Loss</b>。目标可表述为最大化 NDCG@k - λ×推理成本；离线比较不同历史长度分桶，bootstrap 区间决定哪组升级，在路由前冻结评估协议。

实验协议 / 离线指标 / 线上 A/B

业务动机 / 现有瓶颈

搜索与推荐共享 item embedding，通过 raw inner product 做 ANN 时，item norm 会乘上 cos relevance，容易给训练高频商品附加的曝光权重；热门偏差可能不是用户真爱，而是优化过程的几何副作用。

模型架构 / 技术方案与模块

推导 cosine-only loss 对 item output 的局部梯度与当前向量正交；在更新满足切向条件时，非零离散步长使 norm² 增加 ||Δ||²。双任务共享 item tower 时叠加累计可相互暴露这一效应。做 ID-row 更新重缩放受控干预，分解 ID-row tangent 与 shared content encoder 的非切向变化。

训练 / Loss 与监督来源

不是引入新神经网络 loss，核心分析 cosine training 与 unnormalized dot serving 的 metric mismatch；MovieLens/Amazon 采用时间分割、训练集三核和多 seed，专门比较 norm frozen/retracted/intervened。推导只在特定条件成立，不能推广为所有联合 SGD 必然长 norm。

推理 / Serving / 端到端成本

线上要先明确 ANN 使用 dot 还是 cosine、是否 L2 normalize item/query；加 norm 分布、频次 correlation 与被检索头部 item 占比监控。归一化可能改变相关度排序/精排行为，不能把 norm correction 直接视为无损去偏。

实验协议 / 离线指标 / 线上 A/B

MovieLens 32M/Amazon Books 离线的 frequency-norm r 在带内容塔设置下从≈0 到 0.465/0.404；移除 ID 更新即时 norm 增长后回落到 0.199/0.148，但推荐 utility 也损失。实验主要 recommendation-only 日志，未测真实共享 search+rec 联合流量。

与主流方法对比 / 技术优势与局限

相对只从 sampled softmax/popularity negative sampling 分析偏差，本研究提供训练微分几何证据；但原文清楚强调‘非共同 SGD 的无条件定理’，去掉 norm 增量也会伤害 utility，不是开箱即用的改算法。

未解问题 / 研究方向 / 评价推荐落地建议

评价召回中按商品/评价新旧、真实正负观点、热评与长尾评论做分桶；比较 dot/cosine/temperature norm correction 对 Recall@K、满意度、差评覆盖的成本与效果，最终以真实曝光后的去偏 A/B 判断，避免拿 offline popularity variance 充作成交改善。
