Engineering Deep Dive 01 · Model Routing

Semantic Router：把多模型评测升级成 cost-aware policy calibration

Research Impact Score / 研究价值 9.4/10 · 工业成熟度 ★★★★☆ · 创新性 ★★★★☆ · 与你方向的相关度 ★★★★★ · 是否官方开源 是 · 是否有线上 A/B 否 · 阅读优先级 S+

背景 / 现有问题

多模型系统若只优化 accuracy，会不断把流量推向更贵模型；只按 difficulty/confidence 路由又没有成本边界。推荐里的召回源、feature group、ranker depth、reasoning depth 也存在同一矛盾。

技术方案

新工具对每个 task bucket / model 统计 accuracy 与 cost，计算 score = acc − λ × normalized cost 并扫描 λ；在相对 λ=0 的 accuracy drop 不超过容忍度（默认 3pp）时选择成本下降最大的点。输出 mean cost/task 与各模型流量 share，并可生成 routing config；同时加入 evaluation-quality check 与 reasoning-mode eval。

训练 / Serving / 实验

这不是重训基座模型，而是 post-hoc policy calibration。复杂 frontier 搜索放在线下，线上只执行轻量 config。本次合入没有统一 benchmark 数字，示例成本下降不能当正式结论；价值在于把 质量损失、成本、流量份额 纳入同一评测合同。

优劣势 / 局限 / 未来方向

比 static fallback 更能表达 ROI，比纯 difficulty router 更接近生产目标。当前仍是静态 λ 与离线 bucket，尚未纳入 cache hit、queue、P99、业务价值和 switch cost。下一步应做 request-dependent shadow price、contextual bandit / constrained RL。

工程启发

推荐 / 搜索 controller 可统一输出 source、K、feature、model、precision、reasoning depth、halt，目标从 AUC/NDCG 扩展到 value / cost / latency / risk。

Engineering Deep Dive 02 · Determinism

vLLM Batch Invariance：通信优化会进入“同输入是否可复现”的语义

Research Impact Score / 研究价值 9.1/10 · 工业成熟度 ★★★★★ · 创新性 ★★★★☆ · 与你方向的相关度 ★★★★☆ · 是否官方开源 是 · 是否有线上 A/B 否 · 阅读优先级 S

问题：sequence parallel / async TP 会把 all-reduce + RMSNorm 改成 reduce-scatter，而浮点归约顺序随 batch 改变，误差会被 autoregressive decoding 放大。方案：batch invariance 模式暂时禁用 SP / async TP，并补 TP regression test。Serving：这是 correctness-first contract，没有公开统一吞吐损失；生产应同时 benchmark reproducibility 与 P99/QPS。工程启发：A/B 回放、蒸馏、生成式推荐与 RL reward reproduction 都需要记录 determinism mode。

Engineering Deep Dive 03 · Speculative Decoding

TensorRT-LLM：seed 可复现还不够，slot lifecycle 也必须进入 RNG 状态管理

Research Impact Score / 研究价值 9.0/10 · 工业成熟度 ★★★★★ · 创新性 ★★★★☆ · 与你方向的相关度 ★★★★☆ · 是否官方开源 是 · 是否有线上 A/B 否 · 阅读优先级 S

过去 recycled slot 会保留旧 RNG counter，新 seeded request 因而依赖 slot history。修复新增 slot → request_id owner：新请求接管 slot 时 counter 归零，使同 seed 不再依赖历史请求。代码仍明确说明 batch composition 可能改变 per-row subsequence，因此真正的 stochastic contract 包含 seed、slot、batch row、speculation schedule 与 cache state。

Engineering Deep Dive 04 · KV / Memory State

SGLang LMCache：多组件 cache 需要各自的 cursor / backend

Research Impact Score / 研究价值 8.9/10 · 工业成熟度 ★★★★★ · 创新性 ★★★★☆ · 与你方向的相关度 ★★★★☆ · 是否官方开源 是 · 是否有线上 A/B 否 · 阅读优先级 S

统一 prefix cache 同时承载 SWA、Mamba state、外部 LMCache 等组件后，单一 evicted sequence length 容易造成状态错位。本次改为 component_evicted_seqlens，新增 AUXILIARY_SWA，并允许每个 cache 指定 tree core backend。没有速度数字，重点是状态一致性。对推荐的类比是：长期兴趣、session、memory、生成 state 也应拥有独立 version / cursor / TTL。

Paper Deep Dive 01 · Industrial Search Evaluation

SEEK：把评估规则从模型参数拆成可路由、可演进的 Skill Bank

Research Impact Score / 研究价值 9.6/10 · 工业成熟度 ★★★★★ · 创新性 ★★★★★ · 与你方向的相关度 ★★★★★ · 是否官方开源 否 / 未检索到官方仓库 · 是否有线上 A/B 否（已生产部署并有 24k 在线样本评测） · 阅读优先级 S+

背景 / 现有问题

工业搜索需要 page-level evaluator 作为训练与诊断监督。通用 LLM judge 把所有规则塞进 prompt 会产生 criterion interference；把规则 post-train 进参数，又会把每次规则更新绑定到昂贵重训。

技术方案与训练

Skill Bank 外部化 evaluation criteria；Skill Router 为 query–list pair 只选相关 Skill；Listwise Evaluator 判断整页质量并输出 relevance / quality / diversity / authority / heterogeneous attribution；Evolution Controller 从生产错误中抽取 recurring knowledge gap，局部修订 guidance，并用 replay gate 防止伤害旧流量。训练先用 human label + teacher 生成 routing label 与 evidence-grounded trajectory 做 SFT，再用 DAPO 联合 task correctness、skill diagnosis 与 conflict penalty。

实验 / 离线指标

Qwen3-8B 为 evaluator backbone。相对同 backbone SFT+GRPO，三分类 Macro-F1 0.6418 → 0.6555；binary accuracy 0.7520。五维 attribution recall：0.8621 / 0.8102 / 0.6210 / 0.5240 / 0.4305。All Skills 的 accuracy 0.691、Attr.F1 0.664、平均 12 skills；Dynamic Routing 达 0.752 / 0.743 / 3.4 skills；Oracle Routing 0.768 / 0.758 / 3.1 skills。

生产评测 / Serving / 成本

训练使用 H800，生产 inference 部署于 L20 cluster。系统已部署 Kuaishou；24,000 个线上 query–list pairs 上，外包人工 review 36.5h、accuracy 0.783；SEEK 为 0.9h、40.6× speedup、accuracy 0.842。这不是流量 A/B，因此 A/B 字段标记为否。

优劣势 / 局限 / 未来方向

优势是规则可增量、context 更短、attribution 更强；代价是维护 Skill ontology、teacher data 与 replay set。尚缺长期 skill-bank 膨胀、规则冲突治理与跨 vertical 迁移。值得押注 skill utility calibration、hierarchical routing、counterfactual attribution 与 active learning。

工程启发

最重要的范式是 knowledge externalization + conditional activation + replay-gated evolution。复杂业务规则、重排约束、feature policy 都可能从硬编码逻辑变成可检索/可激活 Skill。

Paper Deep Dive 02 · CTR / Ranking Representation

ScalarLens：数值特征的“稳定坐标”与“上下文响应”应解耦

Research Impact Score / 研究价值 9.2/10 · 工业成熟度 ★★★★☆ · 创新性 ★★★★★ · 与你方向的相关度 ★★★★★ · 是否官方开源 否 / 未检索到官方仓库 · 是否有线上 A/B 否 · 阅读优先级 S

背景 / 问题

价格、时长、频次等数值通常被固定 normalization / embedding 表示，但同一个数在不同 user/item/context 下可能有相反点击含义。论文在 Criteo 观察到：去除 additive main effect 后，同 numerical interval 的 residual click evidence 仍会随上下文改变符号。

技术方案 / 训练 / Serving

Monotone Local Mesh 只由 focal scalar 构造稳定 coordinate；Bounded Low-rank Dynamics 根据 context 生成响应变化，而不移动 coordinate。它作为 numerical representation layer 插入现有 CTR backbone，沿用 CTR objective 端到端训练；推理无需依赖外部 normalization 统计同步，但会增加 contextual low-rank branch。

实验

主评测 1,539 runs，覆盖 19 种表示、3 个数据集、9 个 backbone、3 个 seed。原始数值尺度下 27 个 dataset×backbone setting 中 25 个第一、2 个第二；统一标准化重跑后仍显著优于 DEER、DAES、NaryDis。matched ablation 表明 scale correction、额外局部容量、generic conditioning 都不能复现完整收益。

线上 / 效率 / 局限

未披露线上 A/B 与 latency/FLOPs，因此工业成熟度暂定四星。需要继续验证超高 QPS 下的 transform overhead、outlier/missing feature、online drift 以及与 sequence foundation ranker / MoE 的联合效果。

工程启发 / 未来方向

输入表示的 inductive bias 仍可能比“更大 backbone”更有效。值得继续研究 contextual numerical token、monotonic constraint、uncertainty-aware response、feature-wise low-rank sharing 与 online calibration。
