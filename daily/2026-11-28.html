Certify What You Plant: Shortcut-Free Proof Depth in Logical Reasoning Data

Research Impact Score / 研究价值：81/100工业成熟度：公开离线、代码可复现创新性：高：可独立验证的样本结构与你方向的相关度：极高（Reward 数据）是否官方开源：是，作者代码是否有线上 A/B：未披露阅读优先级：S+

Impact 分项（范式 / 工业 / 创新 / 相关 / 后续 / 复现）：82 / 48 / 91 / 97 / 94 / 90；本站主观判断。

背景与业务动机 / 现有问题

合成推理训练中，标注的长推理链不代表任务真正需要这些步骤。模型可以依赖捷径得到正确答案；对应推荐训练中，Generator 可能只学到历史策略排序、长度或曝光位置，而没有识别用户真正需要的评价证据。

技术方案与关键模块

作者以固定推理规则为前提，计算所有证明共有的必要步骤、最短证明、最小证明数量、必要前提，独立 checker 验证证书。先建立可证明的捷径目录，再构造满足目标结构的题目，比先生成再按表面长度筛选更严格。核心区分是「存在长证明」和「所有证明都必须经历指定结构」。

训练方法与目标

第7节对比同模板、同求解器的前向生成样本与认证样本，控制深度、标签分布和样本量；Qwen3 0.6B–8B 混合浅/深题、模态逻辑和 Kripke 模型检查。另用 60 个单种子代理训练拟合数据配比与验证集得分关系，并在新种子确认。结果提示数据组成比单独提高认证深度更重要。

实验设置、离线指标与线上 A/B

八套数据审计中，FLD×2 标称深度5实际约需2个特定步骤；ProofWriter、Blocksworld 的深度更扎实。等量混合数据对 FOLIO 和 ModalBench 的迁移更好，FLD×2基本不变；移除必要前提后仍误判蕴含的现象未解决。论文第7节的受控证据不等于用户线上收益，未披露推荐 A/B。

推理 / Serving 与效率成本

认证和数据配比搜索在线下完成，线上生成模型无需调用求解器；但穷举证明的成本随问题增大上升，部分样本只得到界而非精确值。没有工业 P99 或训练成本收益可直接移植。

主流方法对比、适用场景、局限与未解问题

与普通合成数据相比，证书使数据质量可追溯；但结论依赖选定的推理规则，改变规则会改变必要步数。推荐列表不存在通用逻辑求解器，不能把人工定义的属性覆盖直接等同于用户效用。

未来研究、工程落地与职业技能

建议先构造真实曝光列表的反事实困难样本：固定商品与用户上下文、候选集合、长度及位置分布，只替换关键评价证据或观点覆盖；使用人工双盲和独立模型审核必要性，再训练 List Reward 的成交/满意度双头。按旧策略相似度分桶检查泛化；技能重点是数据诊断、因果实验与独立验收。

Partial Routing: Trace-Tuned Delegation for Resource-Efficient Agentic Workflows

Research Impact Score / 研究价值：75/100工业成熟度：公开 Agent 基准创新性：高：轨迹级子任务路由与你方向的相关度：高是否官方开源：未核验到官方公开实现是否有线上 A/B：未披露阅读优先级：S

Impact 分项（范式 / 工业 / 创新 / 相关 / 后续 / 复现）：81 / 53 / 84 / 86 / 90 / 52；本站主观判断。

背景与业务动机 / 现有问题

请求级大小模型路由忽略一次复杂任务中的局部难度差异。全部走强模型成本高，全部走弱模型可能破坏关键决策；搜索 Agent 的查询改写、证据过滤与最终判断同样不应使用同一预算。

技术方案与关键模块

先用大小模型各自执行历史任务，标记重复子任务、质量与费用，离线生成子任务画像及委派指导；执行时强模型决定何时调用弱模型。参数 δ 控制委派倾向，不代表固定委派比例；该方法是提示与运行时调度，不是训练新的模型。

训练方法与目标

第3–4节使用轨迹 profiling、子任务分类和质量评分，编译为 lead prompt，模型参数冻结。对照独立强/弱模型、无指导委派、仅提供子任务计划、请求级 Jev 和事后 oracle；这样可分离规划信息增益与委派增益。

实验设置、离线指标与线上 A/B

表3：10个留出 ViBench 应用各3次，23个 Terminal-Bench 任务各2次。δ=.75 时 ViBench 70.2→78.5，单任务 $0.83→$0.67；Terminal-Bench 通过率54.3%→60.9%，$1.17→$1.19。仅提供计划也能改善部分指标，说明增益不完全来自弱模型。无推荐线上 A/B。

推理 / Serving 与效率成本

画像离线构建并在模型版本变化后刷新；在线按子任务委派，有额外通信、验证和重试。ViBench 成本下降19%，但另一基准成本略增，API 费用也不等价于端到端 P99；应记录每步 token、重试与最长关键路径。

主流方法对比、适用场景、局限与未解问题

比请求级路由更细粒度，也比训练路由器易部署；缺点是小样本任务分布、依赖可观测轨迹与 lead 的执行纪律。不同模型组合可能改变质量成本曲线，不能将 δ 当普适最优值。

未来研究、工程落地与职业技能

评价推荐可把廉价的重复检测、标签抽取交给小模型，把稀有意图、相互冲突证据和 List 级效用交给强模型；先做仅计划、无指导、画像指导三组对照，再在 P99/总成本预算内上线。技能：Agent tracing、预算控制、分级回退。

Constraint-Aware Test-Time Scoring for LLM and VLM Candidate Selection

Research Impact Score / 研究价值：74/100工业成熟度：公开离线基准创新性：较高：硬验证与软效用分离与你方向的相关度：极高是否官方开源：未核验到官方公开实现是否有线上 A/B：未披露阅读优先级：S

Impact 分项（范式 / 工业 / 创新 / 相关 / 后续 / 复现）：78 / 48 / 82 / 98 / 91 / 45；本站主观判断。

背景与业务动机 / 现有问题

多个候选的语言流畅度和模型自信不能证明它们合规或真实。List Generator 亦可能获得很高 Reward，却输出重复评价、错误商品证据或过度单一的观点。

技术方案与关键模块

三类角色分别生成候选、选择任务软检查配置、对不可程序化的属性评分；先执行硬校验过滤不可行候选，再将软因子归一化并聚合。建议工程实现先明确可行域和业务效用的符号与单调性，避免把惩罚方向写反。

训练方法与目标

零样本任务级配置复用于 M 个候选，无需微调。论文用固定映射统一不同分数，并与等权、单因子及学习组合对照；映射不等于统计校准。实际系统应使用真实曝光验证 Brier/ECE 和 pairwise ordering，而不只看裁判一致性。

实验设置、离线指标与线上 A/B

跨 CWEval、LIBERO、LiveCodeBench、HotpotQA 四个任务。HotpotQA 50问，固定支持与干扰段落，独立模型验收；作者报告联合正确安全指标最高提升0.21，代码安全最高提升0.28。软因子动态配置无稳定额外收益；部分实验使用 gold supporting set，不能把结果视为完整线上检索能力。无推荐线上 A/B。

推理 / Serving 与效率成本

本地4-bit 模型在单台 M4 128GB 环境实验，候选采样与逐候选判分都会增加计算；先做 cheap gate、对通过者再昂贵评分，可控制成本。无可迁移的工业吞吐、P99 或美元成本数字。

主流方法对比、适用场景、局限与未解问题

相对模型置信度、纯 LLM judge 更可审计；但若候选池全错，重排无法恢复。独立验收也可能受裁判误差影响，软权重复杂化未证明有价值。旧首稿（8月31日），本期仅补充精读。

未来研究、工程落地与职业技能

建议在固定候选支持集和计算预算下比较单次生成、best-of-N、硬门槛+等权、硬门槛+学习 Reward；硬门槛只包含可核验商品归属、有效评价、去重，满意度和成交仍由独立真实标签评估。记录 all-fail 回退率、负评覆盖及人工偏好。技能：约束优化、Reward 校准、可审计 Serving。

Aligned Machine: A Benchmark for Evaluating Multimodal Embedding Similarity via Human Comparative Judgements

Research Impact Score / 研究价值：73/100工业成熟度：人类比较标注与离线评测创新性：较高：比较式语义对齐审计与你方向的相关度：极高（内容语义）是否官方开源：未核验到官方公开实现是否有线上 A/B：未披露阅读优先级：S

Impact 分项（范式 / 工业 / 创新 / 相关 / 后续 / 复现）：76 / 47 / 80 / 96 / 89 / 48；本站主观判断。

背景与业务动机 / 现有问题

内容召回依赖向量相似度，但语义相近不必然意味着用户认为有用或相似。多模态向量在图文跨模态任务尤其容易出现对齐偏差；单一相关性标注很难揭示意见分歧。

技术方案与关键模块

设计二选一的比较任务，让人选择两组配对中哪组更相似，并保留标注分布。分别计算图图、图文、文文比较的模型—人类一致率，结合 κ 与多标注方差分析语义判断分歧。

训练方法与目标

这是一套 benchmark 而非新模型训练；使用现有 embedding 计算相似度并与人的二元偏好比较。作为迁移方案，可用 soft target p 表示多数与少数意见，对相似度差训练 Bradley–Terry 式 pairwise loss，按模态和标注一致性分层校准。

实验设置、离线指标与线上 A/B

115人贡献2875次比较、872组唯一配对；评测12个模型。第4节：文本模型一致率 .57–.69，多模态 .522–.565；多模态图图 .585–.635、图文 .515–.561，文文部分低于 .50。各模型只在支持模态上评测，不能把整体差异解释为严格同分布架构优劣。用户参与平台不是推荐随机 A/B。

推理 / Serving 与效率成本

可离线批量计算 embedding 与比较指标，不必增加线上请求延迟；持续采样标注有运营和质检成本。论文未证明召回 P99 或推荐成本下降。

主流方法对比、适用场景、局限与未解问题

比静态相似度标尺更容易表达相对判断和不确定性；样本规模和人群代表性有限，文本相似与购买决策有区别，强制二选一也可能把难分样本硬标为偏好。

未来研究、工程落地与职业技能

针对图文评价设计四类审计：同商品不同属性、同属性不同商品、图文矛盾、正负观点近邻。保留多标注分布，区分语义相似、信息增量和业务效用；分层评测 Recall@K、人工相关性及真实 List 满意度。技能：偏好标注、embedding 评测与难负例挖掘。

Structure-Aware Multimodal Retrieval Under Data Scarcity, Privacy Constraints and Out-of-Domain Content

Research Impact Score / 研究价值：73/100工业成熟度：私有语料盲评、离线原型创新性：较高：布局结构代替跨模态匹配与你方向的相关度：高是否官方开源：作者声明公开；仓库未独立访问成功是否有线上 A/B：未披露阅读优先级：S

Impact 分项（范式 / 工业 / 创新 / 相关 / 后续 / 复现）：73 / 55 / 85 / 84 / 84 / 60；本站主观判断。

背景与业务动机 / 现有问题

专业领域的图片和文本配对样本稀缺，直接使用通用图文编码器容易遭遇分布偏移，隐私又限制上传。结构信息可能比生成的新描述更可靠。

技术方案与关键模块

先解析页面的图像、文本块与版面位置；给本地8B VLM 绘制匿名布局框示意图，选择图片对应的 caption，再用文本 encoder 索引真实 caption。第3.3节以同 caption 合并多面板，过滤小图标；配对阶段不提供原始图像内容或文字。

训练方法与目标

无领域训练、无额外监督，固定版面解析器、VLM 和文本编码器。对比文档 parser、直接图文 embedding、生成图像描述与词法检索。结构配对与内容检索分离，可分别估计误差传播。

实验设置、离线指标与线上 A/B

三个私有领域共29本书、10421图、218查询，盲评。配对准确率96%/92%/77%，较好的 parser 为76%/45%/53%；检索 nDCG@5 为.85/.87/.76，而最佳跨模态 encoder 为.54/.51/.27。布局转文字坐标损失22点。非公开语料且无推荐线上 A/B。

推理 / Serving 与效率成本

布局解析和配对在索引时离线完成，查询只做文本向量检索；结构化示意图降低原内容暴露，但几何元数据亦需权限检查。未核验工业索引吞吐与 P99，不把无需训练等同于零成本。

主流方法对比、适用场景、局限与未解问题

优于域外图像模型的前提是 caption 真实且有信息；无 caption、布局错乱、图文矛盾时可能失效。商品评价的文本与图像关系比教科书图注更弱，不能直接套用准确率。

未来研究、工程落地与职业技能

对图文评价先建立来源绑定、用户原始文本、图像区域等证据记录，再与直接视觉向量做互补召回；随机抽样检验错配、缺文和跨商品图片。比较同预算图文融合与结构索引，监测隐私、索引增量、Recall@K。技能：多模态 IR、数据血缘与索引系统。

背景与业务动机 / 现有问题

通用决策模型能够输出选项或评分，但是否适合接管推荐调参、精排打分或实验搜索必须按角色验证，不能由一个 API 的低成本推断其预测效果。

技术方案与关键模块

Jev 被分别当作完整 optimizer、performance predictor、region guider。第三种只给原生搜索器建议优先探索的参数区间，保留常规反馈闭环；这是把语义先验与数值搜索分工，而非替换所有环节。

训练方法与目标

第3节八项任务每轮100次评估、10个初始样本、30个配对种子；预测器在64个未见候选中比较，每10步一次探索。Jev 将五档结构评分映射回观察值区间；区域指导每10次评估刷新。基线随机、FLASH、SMAC、HEBO、PromiseTune；RF/GP/DaL 对预测角色。无需额外训练 Jev。

实验设置、离线指标与线上 A/B

常规优化器在6/8项排第一，常规预测器在7/8项优于 Jev。区域指导使 A100 困惑度22.392→22.266、RTX2080 22.392→22.267（调整 p<.02），但在其他任务并非普遍改善。不是推荐排序实验，无推荐线上 A/B。

推理 / Serving 与效率成本

完整 API 搜索引入网络时延、费用与稳定性问题。区域指导每轮仅9次 API 调用，表IV 的 GPU 困惑度任务费用约1.7美分/轮（论文定价）；同时仍要计入真实评估成本。不能直接用作线上每请求精排。

主流方法对比、适用场景、局限与未解问题

传统优化器有明确反馈和数值归纳偏置；Jev 更适合提供结构化先验而非盲目替代成熟预测器。研究覆盖有限的配置空间、固定预算和 API 版本，且困惑度不是推荐效用。

未来研究、工程落地与职业技能

建议在评价重排的 Reward 权重、采样温度、候选预算与约束阈值优化中，把 Jev 作为区间建议者，与随机/贝叶斯搜索等预算比较；先做时间外验证再小流量随机试验。独立验证在线模型替代是另一个问题。技能：黑盒优化、统计显著性与自动实验治理。

建议实验路线：先确定瓶颈，再优化生成器

第1周在真实曝光 List 做旧策略、位置、长度、热度等结构基线，构建关键证据替换的困难负例。第2周冻结 Generator 和候选池，比较无约束、硬门槛、等权软分、学习 Reward，分别评估成交与满意度的校准及偏好。第3周测试子任务级模型路由与语义审计，在同等成本下比较质量和 P99。分用户/商品分桶，最终随机 A/B 同时监测成交、满意度、负评可达、回退率及延迟。
